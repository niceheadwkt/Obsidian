漸進式 Web 應用程式（**PWA**, Progressive Web App）可以讓你將網站「安裝」到電腦或手機上，使用體驗就如同原生 App 一樣，且不佔用太多儲存空間。

以下為不同裝置與瀏覽器的詳細安裝步驟：

## 桌面端（Windows / Mac / Chromebook）

### 1. Google Chrome / Microsoft Edge

1. 使用 Chrome 或 Edge 開啟支援 PWA 的網站。
    
2. 觀察**網址列右側**：
    
    - **Chrome**：會出現一個「螢幕加上向下箭頭」的圖示，或是右側的 **「安裝 (Install)」** 按鈕。
        
    - **Edge**：網址列右側會出現由三個正方形加一個加號組成的 **「可用的 App (App available)」** 圖示。
        
3. 點擊該圖示，並在跳出的確認視窗中選擇 **「安裝」**。
    
4. （另一個方法）點擊瀏覽器右上角的 **「三點選單 (⋮)」** $\rightarrow$ 選擇 **「儲存並分享」** 或 **「App」** $\rightarrow$ 點擊 **「安裝此網站為 App」**。
    

## 行動裝置（手機 / 平板）

### 1. Android (安卓)

- **Chrome 瀏覽器**：
    
    1. 開啟網站後，畫面下方通常會自動彈出 **「將 [網站名稱] 新增至主螢幕」** 的提示橫幅，直接點擊即可。
        
    2. 若未彈出提示：點擊右上角 **「三點選單 (⋮)」** $\rightarrow$ 選擇 **「新增至主螢幕」** 或 **「安裝應用程式」** $\rightarrow$ 點擊 **「新增」**。
        

### 2. iOS / iPadOS (iPhone / iPad)

> ⚠️ **注意**：iOS 必須使用 **Safari 瀏覽器** 來安裝 PWA。

1. 使用 **Safari** 開啟網站。
    
2. 點擊畫面底部的 **「分享」** 按鈕（一個方塊搭配向上箭頭 $\uparrow$）。
    
3. 向下滾動選單，找到並點擊 **「新增至主螢幕」** (Add to Home Screen)。
    
4. 確認名稱後，點擊右上角的 **「新增」** 即可。
    

## 如何確認網站是否支援 PWA？

並非所有網站都能安裝為 PWA。一個標準的 PWA 網站必須具備：

1. **HTTPS 安全連線**。
    
2. **Web App Manifest 檔案**（定義 App 名稱、圖示與啟動畫面）。
    
3. **Service Worker**（提供離線快取與背景運作能力）。
    

若網站符合標準，瀏覽器網址列或選單才會顯示「安裝」選項；若不符合，瀏覽器僅會提供普通的「建立捷徑」功能。
