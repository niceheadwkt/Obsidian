# 影片配音標準作業（SOP）

適用：AvaGPT 教學影片等螢幕錄製影片加中文旁白。

## 一、環境（一次性）

| 項目 | 內容 |
|---|---|
| Python | Anaconda（`C:\Users\ch26669\AppData\Local\anaconda3`） |
| 套件 | `pip install edge-tts truststore`（truststore 處理公司網路 SSL 檢查） |
| ffmpeg | `...\anaconda3\Lib\site-packages\imageio_ffmpeg\binaries\ffmpeg-win-x86_64-v7.1.exe`（已寫在腳本內） |
| 壓縮 | 7-Zip `C:\Program Files\7-Zip\7z.exe` |

## 二、標準參數

| 參數 | 值 | 說明 |
|---|---|---|
| 聲音 | `zh-TW-YunJheNeural` | 台灣腔男聲（Windows 內建 Zhiwei 太生硬，不採用） |
| 語速 | `+5%` | 開場句太快時可單段改 `-5%` |
| 音軌 | 原音軌直接取代 | 影片 `-c:v copy` 不重新編碼 |
| 輸出 | `<原檔名>_配音.mp4` | 原檔不動，同資料夾 |

## 三、作業步驟

1. **看影片定時間點**：逐段記下「幾秒開始講 + 講什麼」。旁白要比畫面動作稍早或同步。
2. **寫旁白稿 JSON**（參考 `範例_case1.json`）：
   ```json
   {
     "video": "影片相對於此 JSON 的路徑.mp4",
     "voice": "zh-TW-YunJheNeural",
     "rate": "+5%",
     "segments": [
       { "t": 0.3, "text": "第一段旁白。" },
       { "t": 3.9, "text": "第二段旁白。", "rate": "-5%" }
     ]
   }
   ```
   - 每段可另外指定 `rate` / `voice` 覆寫預設。
   - 專有名詞要讓 TTS 唸對時可改寫，例如「AvaGPT」寫成「Ava GPT」。
3. **先產語音並檢查重疊**：
   ```powershell
   python D:\工作\外部システム\avagpt\建立圖像\voiceover.py 旁白稿.json --tts-only
   ```
   出現 `⚠ 超過下一段/片尾` → 縮短文字、調快語速或往後挪時間點。
4. **合成影片**：
   ```powershell
   python D:\工作\外部システム\avagpt\建立圖像\voiceover.py 旁白稿.json
   ```
5. **修改某幾段**：改 JSON 後只重產那幾段（1 起算），其他段沿用：
   ```powershell
   python ...\voiceover.py 旁白稿.json --only 3 5
   ```
6. **壓縮交付**：
   ```powershell
   & "C:\Program Files\7-Zip\7z.exe" a "<原檔名>_配音.7z" "<原檔名>_配音.mp4"
   ```
7. **工作日誌**：依全域規則記錄並重跑 `generate_html_report.py`。

## 四、合成原理（腳本內 ffmpeg 指令）

```
ffmpeg -nostdin -y -i 影片.mp4 -i 01.mp3 -i 02.mp3 ...
  -filter_complex "[1:a]adelay=300:all=1[a1];[2:a]adelay=3900:all=1[a2];...;
                   [a1][a2]...amix=inputs=N:normalize=0:duration=longest,apad=whole_dur=<影片秒數>[aout]"
  -map 0:v -map [aout] -c:v copy -c:a aac -b:a 192k -t <影片秒數> 影片_配音.mp4
```

- `adelay`：每段延遲到指定時間點（毫秒）。
- `amix normalize=0`：多段混音不降音量。
- `apad` + `-t`：音軌補靜音到影片長度，輸出長度與原片一致。

## 五、常見問題

| 狀況 | 處理 |
|---|---|
| edge-tts `WinError 64` / 連線失敗 | 網路不穩，腳本自動重試 3 次；仍失敗就等網路恢復重跑 |
| SSL 憑證錯誤 | 確認已安裝 `truststore`（腳本開頭已 inject） |
| PowerShell 呼叫 ffmpeg 卡住 | 要加 `-nostdin`（腳本已加） |
| subprocess `cp950` 解碼錯誤 | 加 `encoding="utf-8"`（腳本已加） |
