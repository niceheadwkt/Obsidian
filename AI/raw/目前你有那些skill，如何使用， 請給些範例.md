### 一、 當前活躍的 MCP 整合技能

這些是目前對話中已成功加載的外部服務連接器，能直接讀寫您的個人工作資料：

#### 1. Google Tasks 任務整合技能 (`google-tasks`)

- **功能說明**：透過您自建的 GCP 專案與 OAuth 2.0 授權，可以讀取、搜尋、建立、更新或刪除您 Google Tasks 帳號中的工作表項目。
- **如何使用**：在對話中直接要求我管理您的工作表。
- **使用範例**：
    - 「幫我列出目前 `niceheadwkt的清單` 中的所有任務。」
    - 「在 `niceheadwkt的清單` 中新增一個任務，標題是：『準備下午的 AI Agent 展示簡報』，期限是今天下午五點。」

#### 2. Obsidian 筆記庫整合技能 (`obsidian`)

- **功能說明**：可直接讀取、搜尋、寫入或修改您 Obsidian 庫中的筆記與 Tag。
- **如何使用**：在對話中提及搜尋筆記或讀寫特定筆記內容。
- **使用範例**：
    - 「幫我搜尋 Obsidian 庫中包含『教學檔案處理』關鍵字的筆記。」
    - 「讀取位於 Obsidian/Obsidian/) 資料夾中，關於上次專案進度的筆記。」

### 二、 內建自動化工作流技能

定義於全域規範 AGENTS.md 與專案規範 .agents/AGENTS.md/AI_Agent/.agents/AGENTS.md) 中，會在特定指令下自動觸發：

#### 1. 開工工作流 (Start Work)

- **如何使用**：對我說**「開工」**、**「我來了」**或**「上次做到哪」**。
- **運作機制**：我會自動執行目錄與 Git 檢查，讀取 Obsidian 庫中的最新進度與下一步計畫，並自動檢查 Git 本地與遠端變動，最後向您回報結構化摘要。

#### 2. 收工工作流 (Finish Work)

- **如何使用**：對我說**「收工」**、**「下班」**或**「結束」**。
- **運作機制**：我會自動執行 `git status` 並主動建議 Commit 訊息，經您確認後 Push 至遠端；接著使用 `chezmoi status` 檢查全域設定檔變動，完成敏感資訊檢查後更新 Obsidian 筆記，最後產出完整的收工 Checklist。

#### 3. 語音回覆流程 (Voice Reply Flow)

- **如何使用**：在請求中加上**「用語音回答」**、**「唸給我聽」**或**「用語音講結論」**。
- **運作機制**：我會自動將文字結論以 Edge-TTS 合成語音（預設使用 `zh-TW-YunJheNeural` 男聲），並以行內 MediaPlayer 播放（不開啟外部播放器）。播放完畢後，我只會簡短在文字中回覆「語音已播放完畢」。

#### 4. 語音輸入錯字善意還原 (Voice Input Typos)

- **如何使用**：此為背景自動執行的技能。當您使用語音輸入時，我會自動將同音錯字（例如：`Call Desk` ➜ `Codex`；`Cloud Call` ➜ `Claude Code`；`Typeless` ➜ `headless`）結合上下文語意修正，避免逐字硬解。

### 三、 使用者自訂與專案技能 (Skills)

我們在您的 `.agents`、`.codex` 以及 `C:/aiTest/` 目錄下找到了以下自訂技能：

#### 1. `pdf` (PDF 處理工具包)

- **路徑**：SKILL.md
- **功能說明**：提供 PDF 文字、表格擷取、PDF 合併拆分、旋轉、浮水印添加、密碼加密以及掃描檔 OCR 等自動化處理。
- **使用範例**：「幫我把這份 PDF 的第 1 到 5 頁拆分出來，並用 Python `pdfplumber` 提取裡面的表格。」

#### 2. `finmind-agent` (FinMind 金融資料助理)

- **路徑**：SKILL.md
- **功能說明**：對接 FinMind 金融 API，查詢與分析台美股的財務、基本面、籌碼、量價資訊，並能自動繪製繁體中文分析圖表。
- **使用範例**：「用 FinMind 查詢台積電 (2330) 最近一個月的法人買賣超，並畫成圖表。」

#### 3. `imageConverter` (萬用圖片轉檔與壓縮技能)

- **路徑**：SKILL.md
- **功能說明**：自動進行批次圖片轉檔為 JPG，提供 Smart（智慧減肥）、Limit（大小限制）、Aggressive（強效壓縮）與 Force-JPG 四種模式。
- **使用範例**：「幫我把這個資料夾下的 WEBP 圖檔用 Smart 模式全部轉換成 JPG。」

#### 4. `huashu-nuwa` (女媧 · Skill 造人術)

- **路徑**：SKILL.md
- **功能說明**：透過對某位名人或專家的言論、決策模式進行調研，為其蒸餾並封裝出該人物的思維視角技能 (Perspective Skill)。
- **使用範例**：「我想為黃仁勳建立一個人物思維技能，請幫我分析他的決策風格並封裝為 Skill。」
