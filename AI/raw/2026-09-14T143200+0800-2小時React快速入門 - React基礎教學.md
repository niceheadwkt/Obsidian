### 一、 核心觀念與價值

- **什麼是 React？**
    
    React 是由 Meta (Facebook) 開發並維護的開源 **JavaScript 函式庫（Library）**，主要用於建立使用者介面（UI），特別是單頁應用程式（Single Page Application, SPA）。
    
- **元件化（Component-Based）開發：**
    
    將 UI 拆解為獨立、可複用的元件（Component）。元件在本質上就是回傳 JSX 的 JavaScript 函式，透過組合元件來建構複雜的畫面。
    
- **單向資料流（Unidirectional Data Flow）：**
    
    資料嚴格由父元件透過 `props` 向下傳遞至子元件，確保 UI 狀態變更的可預測性與易維護性。
    

### 二、 JSX 語法特色

- **JavaScript + XML：** 允許在 JavaScript 程式碼中直接撰寫類似 HTML 的標籤結構。
    
- **表示式嵌入：** 在 JSX 中使用單大括號 `{}` 可以直接嵌入 JavaScript 變數、函式呼叫或邏輯運算（例如三元運運算元或 `&&` 判斷）。
    
- **屬性命名規範：** 採用駝峰式命名（CamelCase），例如 HTML 的 `class` 必須寫成 `className`，`for` 必須寫成 `htmlFor`。
    

### 三、 核心狀態與資料傳遞機制

#### 1. Props（屬性傳遞）

- **唯讀（Read-Only）：** 父元件傳給子元件的引數，子元件不可自行修改 `props` 的內容。
    
- **解構賦值（Destructuring）：** 常用解構語法接收傳入的屬性，提高程式碼可讀性。
    

#### 2. useState（狀態管理）

- **響應式更新：** 當元件內部的狀態（State）改變時，React 會自動觸發元件的重新渲染（Re-render）。
    
- **基本語法：** `const [state, setState] = useState(initialValue);`
    
- **不可變性（Immutability）：** 更新陣列或物件型態的 State 時，應建立新的參考（例如使用展開運運算元 `...`），而非直接修改原物件。
    

### 四、 生命週期與 Side Effects

#### `useEffect` Hook

- **用途：** 處理 Side Effects（非同步請求、DOM 操作、訂閱事件、計時器等）。
    
- **依賴陣列（Dependency Array）：**
    
    - `[]`（空陣列）：僅在元件 mount（第一次渲染完畢）時執行一次。
        
    - `[dep1, dep2]`：當依賴項發生變化時重新執行。
        
    - 不傳入陣列：每次元件渲染後都會執行（需注意效能或無限迴圈問題）。
        
- **清除函式（Cleanup Function）：** 在 `useEffect` 中回傳一個函式，用於在元件 unmount 或重新執行 Effect 前清理資源（如 `clearInterval`）。
    

### 五、 清單渲染與條件渲染

- **清單渲染（`map`）：** 使用 JavaScript 的 `.map()` 將陣列資料轉化為 JSX 標籤陣列。
    
- **Key 屬性：** 渲染列表時每個元素必須提供唯一的 `key` 屬性，協助 React 的 Diff 演演算法精準識別與更新變更項。
    
- **條件渲染：** 使用三元運運算元（`condition ? <A/> : <B/>`）或邏輯與運運算元（`condition && <A/>`）來動態顯示 UI。
    

### 六、 實用開發工具與生態系

- **開發工具與建置：** 常搭配 **Vite** 或 **Create React App (CRA)** 快速建立專案環境。
    
- **狀態擴充與擴充套件：** 進階開發常配合 React Router 處理前端路由，或整合 Context API / Redux 進行跨元件全域狀態管理。
