以前做一個 Wordwall 遊戲，題目要一題一題貼。  
想換個玩法，整套再貼一次。  
這次直播我想試的是另一條路：  
把教材丟給 Agent，讓它自己去 Wordwall 把遊戲做出來。  
不是「AI 幫我想題目、我自己貼」，  
是 Agent 從頭到尾自己操作——開頁面、選模板、填內容、存檔。  
Wordwall 沒有開放 API，  
所以這件事的重點不是接 API，是「讓 Agent 學會用一個原本只給人用的網站」。  
這個做法能複製到 Kahoot、Quizizz、任何沒 API 的教學平台。  
這次直播實際做了這些：  
・出題三級：Level 1 純文字、Level 2 考卷截圖、Level 3 AI 生圖，三種都現場跑  
・把國中教育會考的考卷直接截圖變成 Wordwall 題目（根號、幾何圖再也不用自己打）  
・Wordwall 八大題型全部可自動出  
・現場踩到登入的坑，直接請 Agent 改寫流程並更新 repo  
・順帶聊了 Google Spark：輪詢、排程、Webhook 才是它的殺手級  
工具與模型：ChatGPT ＋ Playwright 瀏覽器自動化；模型建議選 Luna 並把推理強度開到最大（省 Token）。  
老師注意一件事：讓學生只輸入班級座號、不要輸入姓名，成績照樣下載得到，去識別化要顧。  
適合誰看：  
・已經在用 Wordwall，但受不了重複貼題目的老師  
・想知道 AI Agent 除了聊天還能幹嘛的人  
・想把自動化用在自己教學現場的人  
不用先會寫程式。看得懂中文就跟得上。
