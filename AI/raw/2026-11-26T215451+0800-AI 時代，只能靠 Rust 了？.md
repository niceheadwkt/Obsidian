### Rust 是什麼：記憶體安全

**0:34** · 要回答這個問題 先來看 Rust 到底是什麼 Rust 是一種編譯式的程式語言 速度和 C++ 是同一個等級 最大的賣點是 記憶體安全 程式在跑的時候 會一直使用電腦的記憶體 用完就要釋放 C 和 C++ 要特別注意記憶體的釋放 很多時候要自己管理 過早釋放或忘了釋放

**0:55** · 都有可能出問題 Python 和 Go 有記憶體自動回收機制 但回收的時候 程式會停一下 而 Rust 走的是第三條路 沒有自動回收機制 每塊記憶體只有一個主人 主人不用了 就自動釋放 別人要用 只能用借的 而且編譯器會檢查每一次借用 舉一個例子 左邊是 C++ 右邊是 Rust

**1:18** · 兩邊都先建一個陣列 再用一個指標 指向陣列的第一個元素 然後在陣列尾端 加一個數字 可是陣列原本的空間已經滿了 只好換一塊更大的記憶體 把資料搬過去 舊的那一塊 vector 會自己釋放掉 但剛剛那個指標 還指向舊的位置

**1:37** · 這段 C++ 編譯器一聲不吭就讓它過了 跑起來 印出來的不是 1 而是一串亂碼一樣的數字 同樣的寫法換成 Rust 編譯就直接失敗 因為還有指標指向第一個元素 也就是還在借用中 陣列就不准改 錯誤停在你的電腦上 不會跑到使用者那邊

**1:57** · 這種錯 連寫了幾十年 C++ 的大公司都躲不掉 Microsoft 說 他們每年修補的安全漏洞 大約七成是記憶體安全的問題 Chrome 團隊統計嚴重的安全漏洞 也是差不多七成 2024 年 美國白宮的一份報告 也建議改用記憶體安全的程式語言 舉的例子就是 Rust 那 Rust 在 AI 這個領域 到底用在哪裡？

### Rust、Python、Go、C++ 比一比

**3:34** · 我們把四個語言放在一起比 先比速度 最慢的是 Python Go 也很快 C++ 和 Rust 最快 是同一個等級 再看記憶體安全 Python 和 Go 靠自動回收 很安全 但回收的時候 程式會停一下 C++ 不會停 但要靠人小心 Rust 兩邊都要 沒有自動回收、不會停

### 標誌是齒輪還是螃蟹？Rust 的名字和 Ferris

**6:59** · 答案是齒輪 中間有個字母 R 的齒輪 才是官方標誌 螃蟹叫 Ferris 是社群的非官方吉祥物 作者放棄了版權 誰都可以拿來用 Rust 這個名字怎麼來的？2006 年 創辦人 Graydon Hoare 回到家 發現大樓電梯的軟體又當機了 他住 21 樓 只好一路爬樓梯上去 他越爬越火大 我們這些寫程式的 連一台不會當機的電梯都做不出來！

**7:24** · 於是他打開筆電 開始設計一個新的語言 他把它取名 Rust 來自一群生命力超強的鏽菌 用他的話說 這種菌是為了活下去而過度設計 所以 Ferris 不是煮熟的螃蟹 那是鐵鏽的顏色 Ferris 唸起來 也很像英文的 ferrous 意思是含鐵的 那為什麼是螃蟹？
