## 重點整理

> 整理日期：2026-11-10｜來源：三師爸 Sense Bar 直播（2026-11-02）

### 一、核心定義：Agent Bot 與 AI Agent 的差別

- **一句話關鍵**：Agent Bot 是「有自己電腦」的雲端 Agent；AI Agent 則是跑在「你的電腦」上。
- 目前主流的三個 Agent Bot：
  | 產品 | 廠商 | 價格 | 備註 |
  | --- | --- | --- | --- |
  | Muse | Meta | 免費 | 臺灣需 VPN 跨區申請 |
  | Grok Bot | Grok | 每月 30 美金 | 講者主力使用、強力推薦；可開多隻 Bot |
  | Dart | ChatGPT | 每月 100 美金 | 用法相同，可語音通話；目前只能有一隻 |

### 二、AI 使用的三個階段

| 階段 | 運作方式 | 優點 | 限制 |
| --- | --- | --- | --- |
| 1. 生成式 AI | 透過瀏覽器連到雲端伺服器 | 生成文字、媒體 | 碰不到本機，產出須自行下載再加工；影片編輯等需本機硬體的工作做不了 |
| 2. AI Agent（代理人 AI） | 本機應用程式搭框架，讓雲端 LLM 帶著權限與工具操作你的電腦 | 可代理人類操作電腦完成工作 | 安全考量下有權限限制；人在外面須靠 Remote Control，彈性不足 |
| 3. Agent Bot | 雲端 AI ＋ 自己的雲端電腦，同時可控制本機 | 結合前兩者優點，手機即可交付工作 | 需付費；本機主機仍須 24 小時開著 |

### 三、工作架構（分層指揮）

```
人類（總指揮：決策、指派、審核）
   │  手機／任何裝置對話
   ▼
雲端 Agent Bot（中間層：調度資源、擁有自己的雲端電腦與已登入帳號）
   │  以 CLI 背景啟動本機 Agent
   ▼
本機 AI Agent（Claude Code、Codex、OpenCode、AGY 等，負責實際重度工作）

另一分支：人類 ──Remote Control──▶ 本機 AI Agent（直接指揮）
```

- Agent Bot 本身**不是最聰明的模型**（無模型選擇、無思考強度設定），定位是「秘書／指揮官」，把需要高智力的工作轉交給本機的頂級 Agent（如 Claude Opus 5.5）。
- 完成後由本機 Agent 回報 Agent Bot，再由 Agent Bot 回報人類。
- Remote Control 仍保留使用，但需事先開啟、無法新開對話或做複雜設定，彈性較 Agent Bot 低。

### 四、為何「有自己的電腦」很關鍵

- 本機 Agent 難以「開啟檔案總管、點選上傳」，上傳 YouTube 須另寫程式並處理授權認證，很麻煩。
- Agent Bot 做法：從本機抓取影片、字幕、metadata 複製到自己的雲端電腦 → 用已登入的 YouTube／粉專帳號直接上傳。
- 在 Agent Bot 的雲端電腦登入 LINE、Facebook、YouTube 等帳號後，它就擁有對應操作權限。
- 安全性：成熟產品會依指示行事，回覆留言等動作須經使用者同意，不會自行亂發。

### 五、講者的實際應用案例（目前五隻 Bot 分工）

1. **影片上架**：手機一句話「幫我上架到 YouTube 和粉專」，自動處理封面、說明、檔案上傳（示範：孟子對荀子饒舌對決）。
2. **指揮本機 Claude Code 做影片**：Grok 開啟 Claude Code CLI 的 Rap Battle 專案；人類審核指出「手部糊掉」，Grok 轉交 Claude 逐秒截圖檢查修正，並產出手機版傳回對話供檢視。
3. **多 Agent 討論投票**：同時開四個 Agent（Codex／Sol 6.1、Claude／Opus 5.5、AGY／Gemini 4 Argon、OpenCode／MiniMax M3.1），加上 Bot 自己共五方討論同一提案、互相投票（不能投自己），回覆結論與優缺點；用於腦力激盪，token 消耗不多。
4. **社群 Bot**：每晚 9 點整理 YouTube 與臉書留言、建議回覆，經同意後代為回覆。
5. **導師 Bot（班務）**：辨識班服名條統計尺寸，存入雲端硬碟「班級事務」資料夾；聯絡本、行事曆、課表、導師匯報皆在同一對話處理。
6. **數感課堂（數學數位教材）**：Bot 當大腦，Claude Code 為主要開發者、Codex 為審核副手，互審提升品質；上課前用手機回報 bug（換座號、交作業失敗、iPad 版面跳動、題目卡住等）並要求限時部署。
7. **邀約／行事曆 Bot**：專門回覆研習邀約信件與排程。

### 六、建置前提與注意事項

- **一臺 24 小時開機的主力電腦**（如 Mac mini 或桌機），記憶體與硬碟要足夠，裝好所有工作用 Agent。
- Grok Bot 應用程式**目前只能連接一臺電腦**；裝在哪臺就能控制哪臺，並與手機 App 對話同步。
- 本機 Agent 的**專案要事先建好**（例如在 Claude Code 中設定好專案），Bot 以 CLI 在背景開啟，不會跳出視窗，可多工並行。
- **雲端硬碟同步**：本機安裝雲端硬碟應用程式，建議用「鏡像」模式（串流有時間差，較不適合複雜工作，但也可用）。
- 多隻 Bot 之間可互相對談、查詢彼此做過的事。
- 用量參考：Grok 30 美金方案以 7 天為週期重設，講者單日用量約 13%，一般工作足夠。

### 七、結論與心法

- 想用好 Agent Bot，**前提仍是要會用本機 Agent**；不會的地方直接問 AI 即可。
- 真正要學的是**「人類 → Agent Bot → 本機 Agent」的邏輯架構**，理解後才能正確分派工作。
- 講者建議：預算有限選 Grok Bot 即可，Dart（100 美金）目前不必購買。
