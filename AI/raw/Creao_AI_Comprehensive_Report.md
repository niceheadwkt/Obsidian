# Creao AI 完整研究與對比報告

本報告詳細整理了關於 **Creao AI** 的平台定位、核心技術、創辦團隊背景、收費模式，以及其與市場上主流開發工具（Claude Code、OpenAI Codex）的深度對比。

---

## 一、 什麼是 Creao AI？

**Creao AI**（[creao.ai](https://creao.ai)）是一個強大的 **AI 代理（AI Agent）與工作流自動化平台**。

它的核心價值在於彌補了以下兩者之間的市場空白：
1. **單純聊天 AI（如 ChatGPT）：** 會話結束後上下文即消失，無法持續運行。
2. **傳統自動化工具（如 Zapier、n8n）：** 需要複雜的 API 串接、硬編碼（Hard-coding）與邏輯設定。

### 核心功能與亮點
* **Super Agent（超級代理）：** 使用者只需使用日常自然語言（中文或英文提示詞）描述需求，系統就能將其轉化為一個具備**長期記憶力、可持續運行**的客製化 AI 應用程式。
* **24/7 自動執行（Agent Harness）：** 設定好排程觸發條件（例如：每 4 小時一次、每週一早上 9 點或 Webhook 觸發），AI 代理就會在雲端背景自動跑完流程。
* **虛擬瀏覽器操作（Browser Use）：** AI 代理擁有獨立的虛擬瀏覽器，能代表使用者登入網站、瀏覽 UI、填寫表單並抓取即時數據，具備隱密渲染與自動破解驗證碼能力。
* **多模態生成能力：** 內建支援生成 4K 圖片、語音合成（支援 24+ 種聲音），並整合 Google Veo 等高階模型生成影片。
* **免 API Key 生態整合：** 支援兩鍵快速連接常用工具，如 **Gmail、Google Sheets、Slack、Notion、GitHub**，並原生支援 **Model Context Protocol (MCP)**。

## 二、 開發團隊與背景

Creao AI 由一家總部位於美國加州庫比蒂諾（Cupertino）的 AI 新創公司於 **2024 年** 創立，並於 2025 年 9 月正式推出產品。其核心創辦團隊擁有深厚的科技巨頭背景：

* **Kai Cheng（程凱）- 創辦人兼執行長 (CEO)：** 擁有超過 10 年為 250 家以上跨國企業建構生產環境 AI 系統的豐富經驗。
* **Peter Pang - 共同創辦人兼技術長 (CTO)：** 先前擔任 **Meta Llama 3 核心團隊** 的研究科學家，專注於生成式 AI 與 LLM 的基礎架構，更早之前於 Apple 負責多模態模型研究。
* **Clark Gao - 共同創辦人兼市場營運負責人 (GTM)：** 先前於 LinkedIn 和騰訊（Tencent）帶領數據團隊，專注於產品商業化與市場推廣。

> **最新發展：** 截至 2026 年，Creao AI 已獲得由沙烏地阿美旗下 Prosperity7 Ventures 領投的 **2,500 萬美元（約合 8 億新台幣）** 融資，全球用戶數已突破 20 萬人。

## 三、 收費模式（Pricing）

Creao AI 採用**免費體驗 + 訂閱制（Freemium）**模式，以「額度（Credits）」與「進階功能（如自動排程）」進行區分：

| 方案名稱 | 每月價格 | 包含額度 | 核心功能與限制 |
| :--- | :--- | :--- | :--- |
| **FREE (免費方案)** | $0 | 註冊贈 30 次<br>每天自動補 5 次 | 支援建立 Agent 與基本連接器。**不支援定時排程**，適合概念測試。 |
| **PRO (專業方案)** | $20<br>*(年繳 $16/月)* | 每月 200 次<br>+ 每天補 5 次 | 解鎖 **Scheduled Runs（定時排程）**、**Memory（長期記憶）**、程式碼執行與網路搜尋。 |
| **PRO PLUS / MAX** | $50 - $150 | 每月 600 - 2000 次 | 適合重度自動化或企業團隊，提供更高的運算速度與專屬技術支援。 |

## 四、 橫向對比：Creao AI vs. Claude Code vs. OpenAI Codex

這三款工具雖然都與「程式碼」或「自動化」相關，但本質上代表了三種截然不同的 AI 應用哲學。

### 綜合對比表格

| 特性 / 產品 | **Creao AI** | **Claude Code** | **OpenAI Codex** |
| :--- | :--- | :--- | :--- |
| **主要定位** | **無程式碼（No-Code）AI 代理平台** | **工程師專用的命令列（CLI）AI 代理** | **程式碼生成大腦（模型 API）** |
| **目標受眾** | 營運團隊、PM、非工程師、自動化愛好者 | 專業軟體工程師、後端與架構師 | 開發 AI 工具的工程師（如 Copilot 早期） |
| **工作環境** | 網頁端瀏覽器、視覺化後台 | 終端機（Terminal）、IDE、本地專案目錄 | 程式碼編輯器內嵌（或透過 API 呼叫） |
| **核心機制** | **化對話為確定性工作流：** 固化對話，使其脫離 AI 獨立、定時在背景運行。 | **自主開發與重構：** 直接在本地目錄讀取專案、改代碼、跑測試、解 Bug。 | **程式碼自動補全：** 根據當前輸入，預測並補全下一行或下一個代碼塊。 |
| **多系統整合** | **極強：** 內建虛擬瀏覽器與各類主流 SaaS（Sheets, Slack, Gmail）連接器。 | **工具鏈整合：** 著重於開發工具鏈（GitHub, GitLab, 本地 CLI 系統）。 | **無：** 純粹的文字/程式碼輸出，無內建工具。 |

### 產品本質深入解析

1. **Creao AI：24/7 在線的「數位員工」**
   * **解決痛點：** 傳統聊天 AI 的成果無法固化。Creao AI 允許非技術人員用「一句話」把一個想法變成一個每天自動執行的雲端腳本（例如：定時爬取競品價格並寫入 Excel）。
2. **Claude Code：幫工程師幹髒活的「虛擬架構師」**
   * **解決痛點：** 專門應對複雜、龐大的 Monorepo（單一巨大程式庫）。它能理解整個專案的架構，自己去修改多個檔案、在終端機跑測試、看 Log 修 Bug，最後幫工程師建好 Pull Request（PR）。
3. **OpenAI Codex：寫程式時的「超級聯想輸入法」**
   * **解決痛點：** 減少工程師查閱語法與撰寫樣板代碼（Boilerplate）的時間。它是 GitHub Copilot 等工具的底層大腦，在你打字時提供下一段代碼的精準預測，但它不會自主執行任務或與外部 SaaS 連動。

## 五、 總結與選型建議

* 如果你 **不會寫程式，或者主要需求是幫公司做跨軟體的自動化工作（如自動對帳、競品監控、定時發報表）** ➡️ 選擇 **Creao AI**。
* 如果你 **本身是工程師，想讓 AI 代理直接進入程式庫（Codebase）幫你重構代碼、修 Bug、寫測試** ➡️ 選擇 **Claude Code**。
* 如果你 **只想在寫程式（VS Code / Cursor）時，讓 AI 幫你快速補全語法、生成基本函數** ➡️ 選擇基於 Codex/GPT 技術的 **GitHub Copilot 或 Cursor 內建補全**。
