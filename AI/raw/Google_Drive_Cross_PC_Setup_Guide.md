# Google Drive 跨電腦 AI 專案協作環境配置與路徑統一指南

本文檔詳細記錄並整理了關於在不同電腦（如學校與家中）建置 AI 專案協作環境時，針對 Google 雲端硬碟路徑差異、舊資料夾殘留、以及同步模式選擇的完整排錯歷程與最佳實踐設定。

---

## 一、 架構與工具定位說明

在「三師爸」式跨電腦 AI 協作架構中，三種主要工具的角色定位如下：

1. **Google 雲端硬碟 (Google Drive)：**
   - **定位：** 跨電腦工作空間與實體檔案儲存地。
   - **核心任務：** 存放 AI Agent 必須讀取的藍圖（如 `agents.md`）、專案資料與關聯檔案。
2. **Obsidian：**
   - **定位：** 本地第二大腦。
   - **核心任務：** 儲存專案細節、架構設計與歷程紀錄（預設不透過第三方自動跨電腦同步，避免衝突）。
3. **GitHub：**
   - **定位：** 程式碼版本控制與備份。
   - **核心任務：** 透過「開工 (pull) / 收工 (push)」指令確保跨設備程式碼完全同步。

---

## 二、 遇到的問題診斷

在配置過程中，發現以下兩個主要問題導致兩台電腦的路徑無法統一：

### 1. 舊殘留資料夾導致路徑帶有 Email 括號
* **現象：** 本機 C 槽 `C:\Users\ch26788\` 目錄下同時存在 `我的雲端硬碟` 與 `我的雲端硬碟 (antonggewkt@gmail.com)`。
* **原因：** 先前曾在本機使用過「雙向同步（鏡像）」模式或切換過帳號，導致系統在 C 槽留下了舊的離線資料夾（如修改日期為舊日期的殘留目錄）。當新版的 Google 雲端硬碟 APP 啟動時偵測到檔名重複，自動加註 Email 括號以區隔。

### 2. 快速存取（Quick Access）舊捷徑混淆
* **現象：** 檔案總管左側面板顯示兩個 `我的雲端硬碟` 圖示。
* **原因：** 左側面板為 Windows 檔案總管的「快速存取」釘選捷徑，部分捷徑指向已失效或舊有的實體資料夾路徑。

## 三、 Google 雲端硬碟同步模式選擇（關鍵設定）

在 Google 雲端硬碟偏好設定中，提供兩種同步模式：

| 評估項目 | 串流檔案 (Stream Files) ⭐【推薦】 | 雙向同步檔案 (Mirror Files) |
| :--- | :--- | :--- |
| **運作機制** | 以虛擬磁碟機（如 `G:\`）掛載雲端檔案 | 將所有雲端檔案完整複製到 C 槽本機資料夾 |
| **檔案路徑格式** | **`G:\我的雲端硬碟\`**（絕對統一） | `C:\Users\<使用者名稱>\我的雲端硬碟 (email)` |
| **跨電腦一致性** | **極高**（不受 Windows 使用者帳號 `userNo` 影響） | **低**（會受 Windows 使用者帳號不同而改變） |
| **C 槽空間佔用** | 幾乎不佔用（僅佔用快取） | 佔用等於雲端容量的本機硬碟空間 |
| **離線存取支援** | 可針對特定資料夾（如 Obsidian）按右鍵設為「可離線存取」 | 強制全盤離線存取 |

### 📌 決策結論：
跨電腦 AI Agent 專案協作**必須選擇「串流檔案」**。
這能確保不論在學校還是家中，AI 程式碼與 Agent 所讀取的路徑均固定為 **`G:\我的雲端硬碟\...`**，避免因 C 槽使用者帳號名稱不同（例如 `ch26788` vs 其他名稱）導致程式碼報錯。

## 四、 完整排錯與清理步驟

若本機出現路徑帶有 Email 括號或路徑混亂情形，請依序執行以下標準作業程序（SOP）：

### 步驟 1：取消快速存取中的舊捷徑
1. 開啟 Windows 檔案總管。
2. 在左側面板對舊的/失效的 `我的雲端硬碟` 按下 **「滑鼠右鍵」**。
3. 點選 **「從快速存取取消釘選」** 📌。

### 步驟 2：安全刪除 C 槽本機殘留舊資料夾
1. 切換至 C 槽使用者目錄（例如 `C:\Users\ch26788\`）。
2. 點進舊的 `我的雲端硬碟`（可依修改日期確認，如舊有日期之資料夾），確認無未備份檔案。
3. 對該舊資料夾點擊 **「右鍵」➔「刪除」**。
   > 💡 **安全說明：** 該舊資料夾已脫離 Google Drive APP 的監控與同步鏈，直接刪除**絕對不會刪除雲端伺服器（網頁端）上的任何資料**。

### 步驟 3：重置並啟動 Google 雲端硬碟 APP
1. 點擊 Windows 右下角系統列（工作列）向上小箭頭 `^`。
2. 點選 Google 雲端硬碟（小雲朵圖示）➔ 右上角 **「齒輪（設定）」** ➔ 選擇 **「結束」**。
3. 按下鍵盤 `Win` 鍵，搜尋並重新開啟 **`Google Drive`**。
4. 在「偏好設定」中，確認同步選項已勾選 **「串流檔案」**。

### 步驟 4：設定個別資料夾之離線存取（如需求）
若專案中的特定資料夾（如 `Obsidian` 筆記庫或 `AI_Agent` 專案檔）需要支援離線編輯與即時同步：
1. 進入 `G:\我的雲端硬碟\`。
2. 對目標資料夾（例如 `Obsidian` 或 `AI_Agent`）按 **「滑鼠右鍵」**。
3. 選擇 **「存取方式」➔「可離線存取」**（圖示會出現綠色圓形打勾符號）。

---

## 五、 最終建議之跨電腦路徑規範

經調整後，學校與家中電腦均採用以下標準路徑規範：

* **雲端主目錄：** `G:\我的雲端硬碟\`
* **AI Agent 藍圖與目錄：** `G:\我的雲端硬碟\AI_Agent\`
* **Obsidian 本地筆記庫：** `G:\我的雲端硬碟\Obsidian\`

透過此配置，可同時實現 **路徑絕對一致**、**不佔用 C 槽空間**、**重要專案支援離線編輯** 三大目標。
