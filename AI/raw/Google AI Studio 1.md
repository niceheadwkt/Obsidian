**[Google AI Studio](https://ai.google.dev/aistudio?hl=zh-tw)** 是 Google 專門為開發者、創作者和企業打造的 **生成式 AI 開發與原型設計平台**。它讓使用者可以直接呼叫並測試 Gemini 系列模型，甚至能把測試好的成果一鍵轉為程式碼或 API 串接到自己的 App 中。

以下為 Google AI Studio 的核心功能與亮點：

### 1. 多元的工作區（Playground）與提示詞測試

在 AI Studio 的主要工作區中，提供不同類型的提示（Prompt）介面，以滿足各種開發情境：

- **Chat Prompts（對話提示）：** 用於建構多輪對話的 AI，例如客服機器人或虛擬助理。你可以透過「輸入-回覆」的範例來訓練 AI 的對話語氣。
    
- **Freeform Prompts（自由格式提示）：** 沒有固定結構，適合用於靈感發想、內容生成（如行銷文案）或是複雜的思維鏈測試。
    
- **Structured Prompts（結構化提示）：** 透過給予明確的範例，強制模型以特定的結構（如 JSON 格式、表格）輸出資料，非常適合需要串接後端資料庫的應用。
    
- **System Instructions（系統指令）：** 可以直接在左側設定 AI 的「人設」、語氣、行為準則，或是限制它只能回答特定範圍內的問題。
    

### 2. 多模態（Multimodal）輸入與超大 Token 視窗

- **多模態處理：** 不只能輸入文字，你還可以上傳**圖片、影片、音訊、PDF 文件**甚至是程式碼檔案，直接讓 Gemini 進行分析、摘要或翻譯。
    
- **百萬級百萬脈絡視窗（Context Window）：** 支援極大的資料吞吐量，你可以一次餵給模型好幾本書或一整段長影片，它都能精確地在裡面撈出你需要的答案。
    

### 3. 進階控制與工具整合

- **模型參數調整：** 介面右側的執行設定面板可以調整 Temperature（隨機性）、Top K、Top P 等參數，以及控制安全設定（Safety Settings）。
    
- **函式呼叫（Function Calling）與程式碼執行：** 允許模型在需要時呼叫外部 API，或者直接在沙盒中執行 Python 程式碼來計算數學題，提升回答的精確度。
    
- **Vibe Coding 與專案生成：** 支援用自然語言直接生成整個專案資料夾，甚至能直接在 AI Studio 中建構以 Kotlin 為基礎的原生 Android 應用程式雛形。
    

### 4. 串接與管理工具

- **Get API Key（取得金鑰）：** 這是許多人使用它的主要目的。當你在網頁端測試好 Prompt 的效果後，可以直接在後台申請免費或付費的 **Gemini API Key**，將這套 AI 能力嵌入自己的產品中。
    
- **一鍵匯出程式碼：** 測試滿意後，點擊「Get Code」，平台會自動幫你把 Prompt 轉化為 JavaScript、Python、cURL、Swift 等程式碼片段，方便複製貼上。
    
- **歷程記錄與範本庫：** **History** 功能會幫你記錄過去的測試成果；**Prompt Gallery** 則提供大量的官方範本，讓新手可以快速複製並改造成自己的應用。
    

---

> 💡 **簡單來說：** Google AI Studio 不是另一個像 Gemini Advanced 的單純聊天網頁，它是一個**「AI 實驗室兼加速器」**。如果你想做出自己的 AI 應用程式，又不想一開始就寫繁瑣的代碼，這裡就是最佳的起點。
