## Claude免費版可以做旅遊行程網站嗎？Artifacts功能、Pro收費比較

**Claude 官方說明，Artifacts（成品）功能適用於免費方案，不需要付費訂閱就能製作旅遊行程網站。** 《數位時代》也實測，使用免費版可直接使用中文對話生成網站，並來回修改頁面設計與功能。

不過，如果希望把網站直接分享給旅伴，或透過 Claude 官方提供的資料儲存功能保留紀錄，就要留意免費版與付費方案的差異。

### Claude Artifacts是什麼？不用寫程式也能製作網站

**Claude Artifacts（成品）是 Anthropic 提供的互動內容製作功能** ，使用者可以透過自然語言建立網站、圖表、文件、儀表板與小型互動工具，並在 Claude 中預覽成果。

以旅遊行程規劃為例，只要告訴 Claude 旅行日期、目的地、網站風格與想要的功能，就能生成包含每日景點、交通指南、住宿資訊、行李清單的行程網站。

網站完成後，也能繼續用中文提出修改要求，例如「把日期切換按鈕放大」、「加入交通時間」或「把整個網站改成日系配色」，讓 Claude 協助調整。

### Claude免費版和Pro差在哪？功能與收費比較一次看

**Claude 免費版就能建立、修改及保留旅遊行程網站，主要差異在於用連結分享成品、官方資料儲存功能與使用額度。**

依據本文實測及 Claude 官方方案資訊，免費版與 Pro 方案差異如下：

這次《數位時代》使用免費版實測時， **打勾、清單與記帳紀錄會保存在使用者的瀏覽器內，換裝置、換瀏覽器或清除瀏覽資料後可能遺失** 。

Pro 方案則支援官方成品資料儲存功能，可依網站設計使用個人或共享儲存，讓成品在不同工作階段之間保留資料。不過依官方說明，透過連結分享給旅伴時，對方只能查看已儲存的紀錄，無法共同修改，因此不能直接用來多人同步打勾或記帳。

另外，Claude 建立網站與反覆修改都會消耗使用額度，免費版可能較快碰到用量上限。

### Claude免費版做好的行程網站怎麼保存？

Claude 免費版製作完成的旅遊行程網站，可以透過 2 種方式保存。

**1\. 保留 Claude 對話與成品**  
網站會存到 Claude 側邊欄的「成品」標籤，從任何對話都能找到；也可以回到原本的對話，繼續要求 Claude 修改。

**2\. 下載 HTML 檔**  
可以請 Claude 提供單一 HTML 檔案，下載到手機或電腦後，用瀏覽器開啟。如果網站的程式碼、圖片與必要資源都包含在檔案內，即使沒有網路，也能查看行程。

須留意，下載 HTML 檔案只能保存網站本身，原本的打勾、清單與記帳紀錄不會直接包含在檔案裡。如果將檔案分享給旅伴，對方可以使用網站功能，但無法看到你先前的操作紀錄，雙方的資料也不會同步。

此外，建議先用免費版完成網站，確認需要用連結分享或官方資料儲存功能後，再考慮升級。

## Claude旅遊行程規劃提示詞怎麼寫？掌握6個設定重點

**首先，開始製作前，記得先確認 Claude 功能設定：**

1. 進入 Claude 的「設定」（Settings）
2. 打開「功能」（Capabilities），確認已開啟「雲端程式碼執行和檔案建立」（Code execution and file creation）。新版設定介面中，這個選項稱為「建立和編輯檔案」

接下來，要做出符合需求的旅遊行程網站，提示詞的寫法在於 **把行程資料、視覺風格、網站導覽與每個頁面的功能描述清楚** 。

如果只輸入「幫我做一個日本旅遊行程網站」，Claude 也能生成網頁，但版面、配色和功能細節可能與原本期待不同。建議提示詞至少包含以下 6 個設定欄位：

| 設定項目 | 要提供的內容 | 提示詞範例 |
| --- | --- | --- |
| 旅程資訊 | 目的地、日期、天數、住宿晚數 | 福岡6天5夜，2026/11/13～11/18 |
| 視覺風格 | 配色、字型、圓角、插圖 | 博多藍 #23406B，圓角16px |
| 導覽方式 | 分頁數量、按鈕位置、切換方式 | 標題下方放四顆大按鈕 |
| 分頁功能 | 每個分頁有哪些資訊 | 首頁放航班、倒數與旅遊插圖 |
| 資訊細節 | 行程卡片、交通與店家資訊 | 餐廳標示菜色、預算與訂位建議 |
| 動畫與其他 | 動態效果、儲存方式、無障礙設定 | 加入輕微動畫，支援減少動態效果 |

提示詞寫得越具體，行程網站越符合需求，建議先列出需要的網站功能與行程資訊，再清楚寫進提示詞，讓 Claude 更準確掌握需求，減少後續修改次數。

## Claude怎麼做旅遊行程網站？4步驟免費製作教學

以下依照《數位時代》使用免費版 Claude 實測，整理成 4 個操作步驟。整個製作過程都能使用繁體中文與 Claude 對話，無須手動撰寫 HTML、CSS 或 JavaScript。

### 步驟1：開啟Claude，輸入旅遊行程網站提示詞

首先前往 [Claude 官網](https://claude.ai/) ，登入帳號並開啟新對話。接著輸入旅遊目的地、日期、想要的網站風格與功能需求。

這次實測特別在提示詞最後加入一句： **「請先閱讀並整理以上需求，提出完整的網站製作規格供我確認。」**

這樣 Claude 會先整理需求，讓使用者確認功能與版面設定，再開始生成網站。由於網站生成和修改會消耗使用額度，先檢查文字版需求，可以降低反覆重做的機會。

### 步驟2：檢查Claude整理的需求，確認網站功能與版面

Claude 整理需求後，可以逐項檢查旅程日期、分頁功能、配色與網站排版。

在這次操作中，Claude 就提出 3 項需要確認的問題：

1. 行程日期換算後，實際住宿晚數與原本設定不一致。
2. 指定的網站字型不一定能直接使用，需要替代方案。
3. 天氣資訊無法依照這次網站的執行方式自動即時更新。

使用者可以直接在對話中回覆修改意見，等確認所有需求後，再請 Claude 開始製作。

### 步驟3：生成旅遊行程網站，使用範例資料測試功能

確認提示詞後，輸入「可以開始製作」，Claude 就會依照需求生成網站。如果還沒訂好機票、住宿，也可以請 Claude：

**「先按照合理的旅遊動線產生範例資料，並在網站上清楚標示『範例』。」**

這樣就能先檢查網站版面、按鈕與時間軸是否符合需求。例如首頁航班卡片是否容易閱讀、每日行程切換是否正常、景點之間的交通段是否清楚，以及記帳和清單能不能操作。

要注意的是，AI 生成的範例資料可能包含虛構內容，不能直接當成正式旅遊資訊使用。

### 步驟4：修改網站設計，加入真實航班、住宿與景點資料

網站完成第一版後，就能透過對話繼續修改。建議一次提出一個明確要求，並說明要修改的位置與預期效果。例如：

- 「首頁最上方的插圖動畫拿掉，其他設計保持不變。」
- 「每日行程的交通資訊要另外獨立成一列。」
- 「把日期切換按鈕放大，方便手機操作。」
- 「住宿卡片加入 Google 地圖連結。」

等網站設計確定後，再把實際訂好的航班、飯店、餐廳與景點資訊提供給 Claude，請它替換原本的範例資料。

**最後記得用手機實際開啟網站，檢查按鈕、地圖連結、記帳、清單與日期切換功能。**

## Claude旅遊行程規劃常見問題FAQ

### Q1：Claude可以免費製作旅遊行程網站嗎？

可以。Claude 免費版支援 Artifacts（成品）功能，能透過中文提示詞建立、修改及保留旅遊行程網站，不需要具備程式設計能力。不過，免費版有使用量限制，用連結分享成品與官方資料儲存功能需要付費方案。

### Q2：Claude一個月多少錢？Pro需要付費嗎？

Claude 提供免費版與付費方案。 **Claude Pro 在台灣 App Store 的訂閱價格為每月新台幣 690 元** 。官網美國定價為每月 20 美元，實際金額可能因訂閱管道、地區與稅費不同而有所差異。

### Q3：不會寫程式，真的可以用Claude做網站嗎？

可以。這次實測全程透過繁體中文描述網站需求，由 Claude 生成程式碼與互動介面。使用者只需要提供旅行日期、目的地、行程資料，以及希望呈現的網站設計與功能。

### Q4：Claude可以規劃東京、京都、首爾等其他城市的行程嗎？

可以。只要修改提示詞中的【一、旅行基本資訊】欄位，填入新的目的地、日期與住宿晚數，再調整網站配色、插圖和購物指南，就能製作不同城市的旅遊行程網站。

例如東京可以指定東京鐵塔、山手線與晴空塔；京都可以使用神社、楓葉、抹茶與日式庭園作為視覺元素。

### Q5：Claude做好的旅遊行程網站怎麼分享給旅伴？

用連結分享成品需要付費方案，而且分享設定要在網頁版或桌面版操作，手機 App 無法更改。免費版可以請 Claude 提供 HTML 檔案，再透過 LINE 或其他通訊軟體傳送給旅伴，讓對方用瀏覽器開啟。

要注意的是，傳送 HTML 檔案不會自動同步雙方的打勾、清單與記帳紀錄。

### Q6：Claude旅遊行程網站可以離線使用嗎？

可以依網站設計提供部分離線功能。若下載的單一 HTML 檔已包含必要的程式碼與資源，就能在沒有網路時查看行程。

不過，Google Maps、即時天氣與線上資料同步等功能仍需要網路。建議出國前先開啟飛航模式測試。

### Q7：Claude行程網站的打勾和記帳紀錄會不會消失？

這次免費版實測中，紀錄會保存在使用者的瀏覽器本機，使用同一裝置、同一瀏覽器通常可以保留，但更換裝置、瀏覽器或清除瀏覽資料後可能遺失。

付費方案支援官方的成品資料儲存功能，可以在不同工作階段之間保留紀錄，製作時要請 Claude 設定對應的儲存方式。依官方說明，用連結分享給旅伴時，對方登入 Claude 後只能查看紀錄。
