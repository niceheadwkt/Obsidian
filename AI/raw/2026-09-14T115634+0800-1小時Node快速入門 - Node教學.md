Node.js 是一個開源、跨平臺的 **JavaScript 執行環境（Runtime Environment）**。簡單來說，它讓 JavaScript 能夠脫離瀏覽器，直接在電腦或伺服器端上執行。

Node.js 的核心概念與重要特點如下：

### 1. 核心特點與價值

- **使用 V8 引擎：** Node.js 採用 Google Chrome 的 V8 JavaScript 引擎，能快速將 JS 程式碼編譯成電腦可執行的機器碼。
    
- **前後端語言統一：** 在 Node.js 出現（2009年）之前，JS 只能在瀏覽器端（前端）執行，後端必須使用 PHP、Python 或 Java 等語言；有了 Node.js，開發者只需學習 JavaScript 一種語言，就能同時撰寫前端與後端。
    
- **原生模組支援：** 提供瀏覽器端沒有的系統級 API，例如操作檔案系統（`fs`）、存取作業系統資訊（`os`）以及建立網路伺服器（`http`）。
    

### 2. Node.js 與 瀏覽器 JavaScript 的比較

|**專案**|**瀏覽器端的 JavaScript**|**Node.js 環境**|
|---|---|---|
|**執行位置**|瀏覽器內（如 Chrome, Edge）|作業系統／伺服器上|
|**DOM 操作**|支援（有 `document`, `window` 物件）|不支援（無 DOM API）|
|**檔案系統**|受限於安全機制，無法直接讀寫電腦檔案|可透過 `fs` 模組自由讀寫本地檔案|
|**模組系統**|僅支援 ES Modules (`import/export`)|預設支援 CommonJS (`require/module.exports`)，也可設定啟用 ES Modules|

### 3. 常見的核心內建模組

- **`os`（作業系統）：** 獲取 CPU 架構、記憶體使用量與作業系統相關資訊。
    
- **`fs`（檔案系統）：** 處理檔案的建立（`writeFile`）、讀取（`readFile`）、刪除（`unlink`）與重新命名等。
    
- **`http`（網路）：** 用於建立 HTTP 伺服器，監聽指定埠（Port）並處理客戶端的 Request 與 Response。
    

### 4. 生態系：npm 與常用套件

Node.js 附帶了 **npm（Node Package Manager）**，是全球最大的開源程式碼套件庫。

- **`package.json`：** 記錄專案資訊與所依賴的第三方套件名稱（`dependencies`）。
    
- **常用套件範例：**
    
    - **Lodash：** 提供陣列與物件處理的工具函式庫。
        
    - **Nodemon：** 開發時使用的工具，能在程式碼變更時自動重啟伺服器。
        
    - **Express：** 熱門的後端 Web 開發框架，簡化路由與 middleware 的撰寫。
