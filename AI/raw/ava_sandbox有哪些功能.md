好的，"ava_sandbox"（您可能指的是 `execute_python_code_mcp_ava_sandbox`）提供了一個安全的 Python 程式碼執行環境，主要具備以下幾大功能：

1. **執行 Python 程式碼**：
    
    - 在一個安全、隔離的沙箱環境中執行任意 Python 程式碼。
    - 這個環境是離線的，無法存取外部網路。
2. **數據分析與計算**：
    
    - 適用於執行精確的數學運算、統計分析和科學計算。
    - 可以用來分析處理 CSV、Excel 等格式的數據文件。
3. **檔案處理**：
    
    - 提供專用的 `sandbox_io` 模組來讀取和儲存檔案。
    - 能夠在對話中暫存檔案，方便在後續的步驟中繼續使用。
4. **Office 文件與 PDF 處理**：
    
    - 針對 Office 文件（.pptx, .docx, .xlsx）和 PDF 文件，有一套標準化且嚴格的處理流程。
    - 對於 Excel 檔案，它能先檢查文件結構（是複雜的儀表板版面還是標準的資料庫格式），再決定最適合的讀取方式，避免格式錯亂。
5. **圖表與視覺化生成 (Kroki)**：
    
    - 支援使用 Kroki 來產生各種圖表和流程圖，例如：
        - **Mermaid**：用於流程圖、時序圖等。
        - **Vega-Lite**：用於數據驅動的圖表，如長條圖、折線圖。
        - **PlantUML**：用於軟體架構圖。
        - **Graphviz**：用於網路關係圖。
    - 可以直接在對話中顯示圖表，或將圖表儲存成圖片檔案。

總結來說，`ava_sandbox` 是一個功能強大的工具，不僅能執行基本的程式碼，更特別強化了在企業環境中常見的數據分析、文件處理和圖表生成等應用。

以下是這些元件的用途與功能說明：

### 1. `sandbox_io` (檔案存取核心)

這個模組是沙箱環境中進行檔案操作的**唯一**途徑，用來確保安全並管理檔案狀態。

- **用途**: 處理所有檔案的讀取、儲存和跨步驟共享。直接使用 `open()` 來讀取使用者上傳的檔案是**不被允許的**。
- **主要功能**:
    - `sandbox_io.get_file(f"${remote_file_path}")`: 從外部（如使用者上傳的檔案）**讀取**一個檔案到沙箱的本地臨時環境中，以便進行處理。
    - `sandbox_io.save_file(local_path, "filename.ext")`: 將沙箱中處理好的結果（例如一個 CSV 或圖片）**儲存**起來，並產生一個給使用者的下載連結。
    - `sandbox_io.save_conversation_tmp_file(...)` & `sandbox_io.get_conversation_tmp_file(...)`: 在**對話中暫存和讀取**檔案。這非常重要，它允許在多個程式碼執行步驟之間傳遞中間檔案，而不會每次都產生一個下載連結。例如，第一步分析數據產生中間檔，第二步讀取該中間檔進行視覺化。

### 2. `sandbox_excel` (智慧型 Excel 處理)

這個模組是專門用來處理複雜的 Excel 檔案，避免因格式問題導致數據分析失敗。

- **用途**: 在使用 `pandas` 這種標準函式庫讀取 Excel 前，先對檔案進行「健康檢查」，判斷其結構類型。
- **主要功能**:
    - `sandbox_excel.inspect(filepath)`: **檢查 Excel 檔案**。這是最關鍵的第一步，它會分析檔案並回報該檔案是「**Layout**」（文件/儀表板類型，有大量合併儲存格和複雜排版）還是「**Database**」（標準的表格數據）。
    - `sandbox_excel.extract_layout(filepath, ...)`: 當檔案被判斷為「Layout」時，使用此功能來**提取文字內容**，它比 `pandas` 更能應對複雜排版。
    - `sandbox_excel.read_layout_as_dataframe(filepath, ...)`: 嘗試將「Layout」類型的檔案轉換為結構化的 DataFrame，是處理複雜報表的利器。

### 3. Kroki (圖表與視覺化引擎)

這不是一個單一的 Python 模組，而是一項整合服務，用於將文字描述轉換為圖表圖片。`ava_sandbox` 透過幾個內建模組來與 Kroki 互動。

- **用途**: 生成所有類型的視覺化圖表，包括流程圖、數據圖、架構圖等，以取代 `matplotlib` 等傳統圖表函式庫。
- **相關元件**:
    - `zlib` & `base64`: 用於將圖表的定義文字（例如 Mermaid 或 Vega-Lite 的程式碼）進行**壓縮和編碼**，使其能透過 URL 傳遞。
    - `requests`: 用於向 Kroki 服務的 URL 發送請求，以**獲取**生成後的圖表圖片（SVG 或 PNG 格式）。
    - `os`: 用於讀取環境變數，以取得正確的內部或外部 Kroki 服務網址。

### 4. `pandas` 和 `openpyxl` (標準數據分析工具)

這些是 Python 生態系中非常普及的數據分析和 Excel 處理函式庫。

- **用途**: 進行強大的數據處理、分析和計算。
- **功能與限制**:
    - `pandas`: 提供 DataFrame 結構，方便進行數據篩選、轉換、聚合等操作。
    - `openpyxl`: 可用於更細緻地讀寫 Excel 檔案的儲存格、樣式和公式。
    - **使用限制**: 在 `ava_sandbox` 中，你**必須**先用 `sandbox_excel.inspect` 檢查，只有當檔案被確認為「Database」類型時，才能安全地使用 `pandas.read_excel()`。

總結來說，`ava_sandbox` 不只是一個單純的 Python 執行環境，它更像一個內建了**安全檔案 I/O (`sandbox_io`)**、**智慧型 Office 文件解析器 (`sandbox_excel`)** 和**現代圖表生成服務 (Kroki)** 的增強型數據分析平台。

在其環境中引用了數個關鍵的 Python 元件（函式庫/模組），以實現其強大的功能。以下是這些元件的詳細說明：

### 內部客製化元件

這些是專為 `ava_sandbox` 環境設計的特殊模組，用以確保安全性和處理特定任務。

1. **`sandbox_io`**
    
    - **用途**: 作為沙箱環境中**唯一的檔案存取管道**，負責安全地讀取、寫入以及在對話中傳遞檔案。
    - **主要功能**:
        - `get_file(path)`: 從外部（例如使用者上傳的檔案）讀取檔案到沙箱的本地環境中，以便進行後續處理。
        - `save_file(local_path, new_name)`: 將在沙箱中產生的結果（如分析後的報告、圖表圖片）儲存起來，並提供一個下載連結給使用者。
        - `save_conversation_tmp_file()` / `get_conversation_tmp_file()`: 在同一個對話的多個步驟之間**傳遞暫存檔案**。這是實現複雜工作流程的關鍵，例如第一步處理資料，第二步讀取中間檔來產生圖表。
2. **`sandbox_excel`**
    
    - **用途**: 智慧地處理結構複雜的 Excel 檔案，防止在使用 `pandas` 等標準工具時因格式錯亂而導致分析失敗。
    - **主要功能**:
        - `inspect(filepath)`: **對 Excel 檔案進行「健康檢查」**。它會分析檔案並回報其類型是「Layout」（包含大量合併儲存格、排版複雜的儀表板或表單）還是「Database」（標準的表格資料）。這是使用此模組最關鍵的第一步。
        - `extract_layout(filepath)`: 當檔案被識別為「Layout」時，用此功能來提取文字內容。
        - `read_layout_as_dataframe(filepath)`: 嘗試將「Layout」類型的複雜報表轉換為結構化的 `pandas` DataFrame，是處理這類檔案的利器。

### 標準 Python 函式庫

這些是廣泛使用的開源 Python 函式庫，在沙箱中提供了核心的計算與處理能力。

3. **`pandas`**
    
    - **用途**: 進行高效的**數據分析和資料操作**，是 Python 數據科學的核心工具。
    - **主要功能**: 提供 `DataFrame` 這個二維表格資料結構，可以輕鬆地進行資料篩選、排序、分組、聚合、計算等操作。在沙箱中，強烈建議**先用 `sandbox_excel` 檢查**，確認檔案是「Database」類型後再使用 `pandas.read_excel()`。
4. **`openpyxl`**
    
    - **用途**: 專門用於讀取和寫入 Excel 2010+ (`.xlsx`/`.xlsm`) 檔案。
    - **主要功能**: 提供了比 `pandas`更底層、更細緻的 Excel 操作能力，例如讀寫特定儲存格、操作公式、樣式等。適用於需要精確控制 Excel 檔案內容的場景。
5. **`requests`**
    
    - **用途**: 發送 HTTP 網路請求。在 `ava_sandbox` 這個**離線環境**中，它的用途被嚴格限制。
    - **主要功能**: 唯一指定的用途是與內部的 **Kroki 服務**溝通，將圖表定義發送過去，並接收回傳的圖表圖片。
6. **`zlib` 和 `base64`**
    
    - **用途**: 用於**資料的壓縮與編碼**。
    - **主要功能**: 在與 Kroki 服務溝通時，會先使用 `zlib` 將圖表定義文字（例如 Mermaid 語法）進行壓縮，再使用 `base64` 將壓縮後的二進位資料編碼成 URL 安全的文字格式，以便嵌入到請求網址中。
7. **`os`**
    
    - **用途**: 提供與作業系統互動的功能。
    - **主要功能**: 在沙箱中，其主要功能被限制在讀取環境變數，例如透過 `os.getenv()` 來獲取 Kroki 服務的內部網址。
