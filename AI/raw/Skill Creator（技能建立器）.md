**Skill Creator（技能建立器）** 的能力：協助您設計、編寫並部署自訂的 Skill。

以下是我可以如何協助您建立 Skill 的方式：

### 1. 互動式建立 (我來為您編寫)

您可以直接對我說：「**幫我建立一個 [技能名稱] 的 Skill**」並說明您的需求（例如：自動撰寫 Git Commit 規範、檢查程式碼格式、或是特定 API 的開發規範）。 我會引導您完成以下步驟：

1. **定義觸發條件**：設定 YAML Frontmatter 中的 `name` 與 `description`，以決定未來在什麼對話情境下會自動觸發此技能。
2. **編寫指令 (SKILL.md)**：為我撰寫詳細的處理指南與步驟。
3. **儲存至正確路徑**：
    - **專案層級**：儲存於專案目錄下的 .agents/skills/。
    - **全域層級**：儲存於全域設定下的 `C:/Users/ch26788/.gemini/config/skills/`。

---

### 2. 使用 `/learn` 斜線指令

當我們在對話中解決了某個複雜的環境設定，或者您對我的回答進行了關鍵修正，且希望未來我都能記住這個規則時，您可以推薦使用 **`/learn`** 指令。

- 系統會引導我將目前的經驗自動整理並儲存為新的 Skill 或規則（存入 AGENTS.md 或 Skill 目錄下），實現自動化「技能學習」。


> [!NOTE]
> ```text
> 用 Skill Creator 幫我建一個『報帳小幫手』的 Skill。
> 
> **我的工作場景：** 我會上傳一堆發票、計程車收據和高鐵票的照片。
> 
> **你的任務：** 自動辨識照片內容，幫我整理成一個表格。請務必提取以下欄位：  
> 消費日期  
> 項目名稱（如：交通、餐飲）  
> 發票號碼  
> 總金額  
> **回報格式：** 最後請輸出成 Excel。
> ```
