# Claude Design 與前端美化實務

**Claude Design 與前端美化實務** 探討了 Anthropic 最新推出的 Claude Design 前端 UI/UX 視覺美化引擎。這套工具整合了即時程式碼預覽、互動式微調以及標註留言功能，讓非技術背景的設計師或開發者能夠以直觀、所見即所得的方式，將粗糙的前端網頁或簡報提煉出世界級的品牌設計質感。

---

## 1. Claude Design 核心功能與互動微調機制

Claude Design 的運作邏輯是將 AI 的代碼寫入能力與網頁渲染引擎結合。在您輸入前端代碼或簡報大綱後，右側會彈出獨立的互動視窗，支援以下三種核心微調手段：

### 1. XML Prompt (XML 提示詞結構)
在要求 Claude Design 進行排版與配色時，使用結構化的 XML 標記包裹設計規範，能讓 AI 以極高的依從度執行樣式渲染。例如：
```xml
<design_spec>
  <theme>Minimalist Business</theme>
  <primary_color>#0033aa</primary_color> <!-- 皇家藍 -->
  <secondary_color>#f4f4f4</secondary_color>
  <border_radius>8px</border_radius>
  <layout_grid>3_columns</layout_grid>
</design_spec>
```

### 2. Slider (滑動條數值微調)
在右側預覽介面中，系統提供了視覺化的滑動條 (Sliders)。使用者可以直接用滑鼠左右拖動滑動條，微調元件的**間距 (Padding/Margin)**、**圓角弧度 (Border-radius)**、**字體粗細 (Font-weight)** 或**陰影深度 (Box-shadow)**。調整後，Claude 會自動在左側後台重寫對應的 CSS 樣式代碼。

### 3. Comment (線上標註留言修改)
這是最富革命性的協作方式：
*   **操作**：直接在右側預覽畫面上，用滑鼠拖曳框選需要修改的區域（如：一個偏小的按鈕或是不對齊的表格）。
*   **留言**：在彈出的輸入框中直接打字（如：「請將此按鈕的字體加粗，並將背景顏色換成深灰色」）。
*   **執行**：Claude 會精確定位被框選區域的 HTML/CSS 圖層，並僅針對該局部代碼進行重構，避免整頁重寫。

### 4. 互動視覺功能 (Interactive Visualization)
最新的 **「互動視覺 (Interactive Visualization)」** 功能允許用戶直接在對話框中生成可互動的圖表與視覺看板。AI 能即時處理複雜的數據，並在預覽中渲染出動態的長條圖、折線圖或雷達圖，無需安裝額外的套件（詳見 [[raw/2026-06-15T160047+0800-Claude推「互動視覺」新功能，可以直接在對話框裡畫圖表.md|Claude 互動視覺功能說明]]）。

## 2. 商業美學實踐：麥肯錫風格 (McKinsey Style)

在商業匯報與高端產品提案中，「麥肯錫風」是極受歡迎的極簡商務視覺設計。

### 🎨 麥肯錫風格要素
*   **色彩系統**：純白或極淺米色背景（90% 佔比）、**皇家藍 (Royal Blue)** 作為核心聚焦色、暗灰與香檳金作為輔助與點綴。
*   **排版美學**：精品級的無襯線字體、嚴格的網格系統（Grid System）、強大的對比度與**高達 40% 以上的留白率**，拒絕花哨的過渡裝飾。

### 📝 麥肯錫風 Prompt 範本
當使用 Claude Design 生成簡報或網頁 UI 時，可輸入以下指令：

```markdown
請將此頁面的 UI 排版美化為「麥肯錫商業諮詢風」。請遵循以下視覺指南：
1. 配色：主色使用皇家藍 (#0A2540)，輔色使用優雅的暗銀灰 (#F6F9FC)，背景為純白。
2. 排版：使用現代無襯線字體，行高設為 1.6 倍，整體畫面保持 45% 以上的高留白率，營造呼吸感。
3. 元件：所有的數據卡片與表格，使用微弱的柔和陰影與 6px 圓角邊框，並以嚴格的網格系統 (CSS Grid) 水平與垂直對齊，呈現高端、專業且清晰的商業提案美感。
```

## 3. 搭檔 Refero 進行 Token 節省優化

由於 Claude Design 在渲染與反覆修改視覺元件時需要頻繁讀寫整個 HTML/CSS 程式碼，這會導致對話上下文迅速飆升，極易達到單日用量上限。

### 💡 搭配 Refero 設計庫優化
*   **原理**：**Refero** 是一個收集了全球頂尖 SaaS 與品牌網頁設計組件（如：登入頁面、定價表格、導覽列）的視覺參考庫。
*   **實踐**：
    1.  先在 Refero 上找到您心儀的設計組件。
    2.  將該組件的排版邏輯與配色，精簡成簡短的文字規格（例如：「Refero 類型的左側導覽列，含圓角微凸的 Hover 效果」）。
    3.  僅將此精簡規格提供給 Claude Design 作為引導。
*   **效果**：這能精準定位 AI 的視覺方向，**避免 AI 反覆盲目生成數十次**而燒光 Token。

## 4. Claude Design 設計定位與工作流整合
綜合 [[raw/Claude Design.md|Claude Design 核心特點指南]]，這款工具的定位是在自然語言驅動下實現「左對話、右畫布」的獨立原型打樣環境：

### ▍ 核心工作流特點
*   **品牌自適應 (Brand-Aware)**：系統能自動讀取公司網站、Logo、色票，甚至連接 GitHub，自動在後台建立與對齊品牌一致的「設計系統 (Design System)」。
*   **多維度素材匯入**：支持直接上傳 DOCX、PPTX、XLSX、PDF 文件，將文字數據自動轉換為對應的設計稿；亦可直接上傳現有產品網頁截圖要求 AI 學習其視覺風格。
*   **工程交接 (Handoff)**：支持將視覺原型一鍵 Handoff 交接給 [[Claude]] Code 或本地 Agent 轉化為真正的產品代碼，或匯出為 HTML 網頁與 Canva 連接。

### ▍ 與主流設計工具的對比與分工
在現代 AI 輔助工作流中，不同設計工具各司其職：

| **比較維度** | **Claude Design** | **Figma** | **Canva** |
| :--- | :--- | :--- | :--- |
| **主要定位** | **對話式原型工作台** | 專業設計與深度協作平台 | 視覺素材快速製作與發布平台 |
| **核心優勢** | 意圖理解、快速將想法視覺化 | 細部精準控制、Auto-layout 與元件庫 | 大量內容範本與快速社群媒體排版 |
| **適用對象** | PM、行銷主管、創業者、前端工程師 | 專業 UI/UX 設計師 | 社群小編、行銷執行人員、非設計專業者 |
| **工作流分工** | 負責**「靈魂」**（概念、結構與快速打樣） | 負責**「細節」**（高保真設計、多人協作） | 負責**「皮囊」**（視覺美化、延伸大量素材） |

### ▍ 使用門檻與額度控制
*   **使用方式**：Pro/Max/Team 等級訂閱用戶可於 `claude.ai/design` 直接使用。
*   **額度控制**：由於涉及高密度視覺推理，其 Token 消耗量大於普通 Chat。建議**在備妥具體文字大綱、品牌素材及「提示詞四要素（目標、排版、內容、受眾）」**後再行發起，並善用 Refero 參考以減少不必要的對話迭代。

## 5. 實戰技巧：AI 改造原廠 PPT（去 Logo、套公司模板）

當需要把國外原廠提供的 PowerPoint 改造成公司自己的簡報時，**不要直接叫 AI「把這 30 頁改成我們公司的 PPT」**——這容易讓 AI 把原廠頁面邏輯、背景、Logo 與企業色一併留下。正確順序應「先理順內容，最後才套模板」，拆成四段指令：

1. **拆開內容與品牌元素**：要求 AI 逐頁整理產品名稱、規格、數據、案例等資訊並保留來源頁碼，同時標示出品牌故事、Logo、企業色等裝飾元素先不帶入；**關鍵防線是要求「數字、單位和規格不得自行補寫」**。
2. **篩選這次真正要用的資料**：依提案目的，將資訊分成「一定要用／可放附錄／不需要」三類並說明原因、保留頁碼，篩完仍要自己核對一次型號與數字。
3. **配公司既有版型**：提供公司範本，請 AI 辨認既有版型後逐頁指定配版，只使用提供的模板邏輯，不沿用原廠背景／Logo／企業色。
4. **重建成可編輯 PPTX**：只用已確認的文字數據製作，不自行補寫；沒有乾淨的產品照／原廠視覺素材時標示「需向原廠索取素材」；完成後列出每頁對應的原廠頁碼供最後核對。

> [!TIP]
> 若浮水印、灰點已與背景圖片合成，不建議叫 AI「去浮水印」；更好做法是把素材分兩類處理——文字/數據/表格類直接用公司字體重做，產品照/Logo/原廠視覺類則直接向原廠索取乾淨檔案。

## 6. AI 簡報方法論：特殊洞察 × 個性表達（KH3R）

三師爸提出「AI 時代的一份好簡報」核心觀點：多數人用 AI 做簡報時只是「問問題 → 讓 AI 產內容 → 直接拿來用」，結果導致內容同質化、沒有靈魂。一份好的 AI 簡報必須具備兩個核心：

### ① 特殊洞察（決定「說什麼」）
不是提示詞本身，而是你的人生經驗、專業判斷與實戰累積——這是 AI 無法複製的部分。公式：**個人經驗 ＋ 核心想法 ＋ AI 整理 ＝ 無法被取代的內容**。洞察來源可分四個維度：專業、生活經驗、長期觀察吸收的新知、實作累積（成功或失敗經驗皆可）。

### ② 個性表達（決定「如何被記住」）：KH3R 法則
一場好的展演至少需包含以下元素中的兩項以上：
- **K – Knowledge**：真正想傳遞的核心知識
- **H – Happiness**：有趣、幽默，讓人想聽下去
- **R – Resonance（共鳴）**：舉例是否讓聽眾有共鳴
- **R – Response（回應）**：能否引發互動與回應
- **R – Rhythm（節奏）**：獨有的敘事節奏與表達方式

> [!TIP]
> AI 只能整理已知資訊、只能單向輸出、沒辦法知道你的聽眾是誰；而人類展演具備肢體動作、眼神、現場互動與自己的節奏——這些都是 AI 無法取代的部分。真正的危險不是被 AI 取代，而是**你表達的內容變得跟 AI 沒有分別**。此觀點與 `[[Wordwall 與教育科技的 AI Agent 自動化實務]]` 中「AI Agent 是專業能力的放大器」核心主張互為呼應。
