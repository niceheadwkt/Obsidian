# 不用本機顯卡的 AI 影片工作流：Colab 與 Seedance

三師爸 Sense Bar 2026-10-23 颱風假直播（約 2 小時 25 分），用同一份「颱風假」短劇腳本，同時跑兩條付費路線並當場比較：**租 Google Colab 雲端主機跑 MiniMax H3**（便宜），以及**在 Kie.ai 儲值、用 API 呼叫 Seedance 2.5**（品質天花板）。全程只在 Agent（Claude Code）對話裡完成，不開 ComfyUI、不進剪輯軟體。raw 原檔只有影片連結，2026-11-23 補入 YouTube 字幕後整理。金額與單元數為直播當下的口述。

**一句話重點**：靜態鏡頭用 Colab，誇張動作再交給 Seedance

## 一、兩條路線比較

| 項目 | Colab＋MiniMax H3 | Kie.ai＋Seedance 2.5 |
|---|---|---|
| 是什麼 | 租 Google 雲端主機（RTX PRO 6000 96GB，買一台約 60 萬），在上面裝本機生成工具 | 雲端影片生成 API，目前 AI 影片品質天花板 |
| 計費 | 100 單元約 10 美元；工作流每小時約 8.9 單元（約台幣 30 元）| 儲值點數（50 美元 1 萬點），約**每秒 10 元**，重抽另計 |
| 本次 90 秒短片實際花費 | 本機 14 支＋Colab 12 支鏡頭，Colab 只用 **1.43 單元**，約 12～15 分鐘跑完 | 約 **1,070 元**；忘了附角色參考音，聲音不是原角色 |
| 品質 | 靜態講話鏡頭不錯；會有提示詞不遵循、表情動作較弱 | 表情、動作、提示詞遵循度明顯較好 |
| 適合 | 平常大量製作、預算有限 | 有經費、需要高品質或複雜動作 |

- **Google AI Pro 每月附 200 個 Colab 單元**（需實際付費，教育帳號、試用、贈送都不算；90 天後過期），換算約可開主機 22 小時。
- 講者目前的做法是**混搭**：靜態、講話鏡頭用本地或 Colab 的 H3；跑步、武打、跳舞等誇張動作改送 **Seedance 2.0 Mini**（同一段約 902 點，2.5 要 6,930 點），品質仍比 H3 好很多，最後由 Agent 自動剪在一起。

## 二、Colab 怎麼接到 Agent

1. 在 Agent 裡說「請協助我連接主帳號的 Colab」，Agent 會用 **Colab CLI** 開瀏覽器登入（需手機驗證）。
2. 授權頁勾選 Google OAuth Library，頁面最下方會出現一組 code，貼回 Agent 的終端機即完成；之後登入與單元餘額都由 Agent 代管。
3. 把講者的兩個 GitHub repo 交給 Agent：一個是「連到 Colab 的雲端工作流」，一個是「架在雲端主機上的 MiniMax H3（32G VRAM＋64G RAM 版）」，請它照 repo 建置。Agent 會開美國的 G4 機器，直接從官方下載安裝，約 3～5 分鐘裝好。
4. 工作流在 Colab 開**兩個 ComfyUI**，第二個延後 30 秒啟動、補第一個的空檔，速度約 1.5 倍；本機有顯卡時可再加一個一起跑。
5. **用完就關**：關機後主機內容全部刪除，只保留下載回來的成品；下次重開再裝一次（3～5 分鐘）。審片若能在 5 分鐘內完成可以先不關；要修改時**整部看完一次講完**，避免反覆開關。
6. Colab 不只能生影片：電腦跑不動的聲音合成、其他本地 AI 測試也可以丟上去跑，再把成果下載回來。

## 三、Seedance 2.5 怎麼接

- 到 **Kie.ai** 註冊、儲值（點數制，不是訂閱，用不完會留著），建立 API Key 交給 Agent，平台上的 Seedance、Kling、Wan 等模型都能從 Agent 呼叫，依各模型價格扣點。
- 一鏡最長可到 30 秒，但後段難控制、重生成本高，一般仍以 **5～12 秒**一鏡為主。
- 解析度：用 **720p 生成再放大到 1080p** 最划算；480p 放大到 1080p 效果有限，直接生 1080p 太貴。
- 教訓：本次忘了送**角色參考音**，聲音變成模型自己配的；直播中請 Agent 把「Seedance 工作流必須附角色參考音」寫回 repo。

## 四、完整製作流程

| 步驟 | 做法 | 重點 |
|---|---|---|
| 1. 腳本 | repo 內附「山獅霸 Drama」編劇技能 | 先給自己的點子與觀察（例：老師怕進度落後先派作業、學生熬夜刷縣市長臉書），再請它上網找共鳴梗；敏感或低俗的梗刪掉 |
| 2. 角色資產 | 用 Codex（OpenAI Image 2.5）生圖 | 不用訓練 LoRA；每個角色一張定裝照（全身正面、正面近照、四分之三近照）加轉面圖，存在本機專案資料夾，依系列分資料夾；場景（如教室前後兩向）和聲音也做成資產 |
| 3. 試映本 | 16 宮格分鏡草圖＋配音讀本 | 還沒花算力生影片前，先看節奏、聽片長；發音錯（例：「颱」）在這裡修 |
| 4. 首幀 | 每一鏡的第一張圖都先畫好 | 一部短片可能要 20～30 張，每張抽 2～3 版挑一張；可控度比「只給角色、其餘靠提示詞」高 |
| 5. 先聲音再影片 | 聲音定稿後才生影片 | 影片依聲音對嘴型；先生影片再配音嘴型會對不上 |
| 6. 生成與組裝 | Agent 分配給 Colab、本機或 Seedance | 自動剪接、上字幕，人只負責審 |

- 預設 **9:16 直式**（臉書觸及較好）；校慶、園遊會等場合要橫式需另外指定。
- 生圖建議走 **Codex CLI**（吃 ChatGPT 訂閱額度，不另外付費）；用 Claude Code 或 Antigravity 時，請它呼叫 Codex CLI 的 Image Gen。
- 中國模型配出來容易是大陸腔，要台灣腔得另外用台灣腔 TTS 修，很花工；Gemini TTS 不能生成小朋友的聲音。

## 五、硬體與時間

- 完全本機生成：至少 **16GB VRAM**（4060 Ti 16G 可跑但吃力），建議 5070 Ti、5080；8～12GB 只能跑量化模型，品質差。講者不建議買 DGX Spark。
- 熟練後一部 1～1.5 分鐘短片從發想到審完約 3 小時，一天可做 6～7 部；AI 影片目前仍以 1～3 分鐘為主。
- 講者認為**腳本才是最有價值的部分**：工具大家都會用之後，比的是內容有沒有共鳴；老師的教學現場經驗是外人做不出來的素材。

## 我可以怎麼用

- **公司訂閱的 Colab 單元別浪費**：若有付費 Google AI Pro，每月 200 單元可拿來跑本機跑不動的模型（語音合成、OCR、影片），用完記得請 Agent 關機。
- **EA 教育訓練影片可走混搭**：投影片加旁白這種靜態內容不需要 Seedance；真的要示範現場操作動作時，才考慮送 Seedance 2.0 Mini。
- **「先試映、再花錢」的思路**：先用便宜的草稿（16 宮格加配音）確認節奏與錯字，再送高成本生成，跟 ERP 先在測試機驗證、再上正式機是同一個道理。
- **改動一次講完**：雲端資源按時間計費時，把所有修改整理成一張清單一次送出，比逐項來回便宜。
- **把教訓寫回工作流**：漏附參考音後當場要求 Agent 更新 repo 的檢查項目；自己的 Skill 遇到錯誤時也照這樣做。
