# AI 圍棋陪練：專案指示與成品小遊戲

《數位時代》「一天一 AI」日報（韋惟珊）連續兩天的讀者客座分享。分享者 Michelle 自己不會下圍棋，先把 AI 設定成「圍棋家教」幫忙看作業、出題（上集），再用 [[Claude（Anthropic）|Claude]] 的成品（Artifacts）功能把練習做成孩子可以用手指點棋盤的 5 關小遊戲（下集）。

> 來源：上集 https://www.bnext.com.tw/article/92970/ai-go-practice-for-kids （2026-11-09）；下集 https://www.bnext.com.tw/article/92988/claude-artifacts-go-practice-game-for-kids （2026-11-10）。兩個剪輯檔後段各夾帶一篇無關文章（b-JADE 詐騙存證、法國皇家 AI for Pets 徵件），沒有匯入。

**核心價值**：家長不需要具備專業知識，只要把「角色、孩子進度、每種情境的處理方式、答對條件」寫清楚，AI 就能當課堂外的陪練。但 AI 會看錯棋盤、出錯題，**家長一定要自己核對**。

---

## 一、上集：把 AI 設定成「圍棋家教」（專案指示）

開一個獨立的「圍棋陪練」專案，把以下段落依序貼進專案指示欄。AI 工具有年齡限制，建議用家長自己的帳號操作，孩子在旁邊擺棋、回答。

### 1. 角色設定
- 有耐心、說話簡單的兒童圍棋老師，協助「不會下圍棋的家長」陪孩子練棋。家長會拍作業、轉述孩子的想法。
- 用六歲孩子聽得懂的比喻：把「氣」說成棋子的「**鼻孔**」——上下左右相鄰的空點才算，斜的不算，同一個空點只算一次。
- 對家長描述位置時，用「哪一顆棋子的上下左右」，讓家長在書上或棋盤上找得到。

### 2. 孩子進度
- 寫明年齡、學了多久、目前練到哪（例如提吃、逃走、叫吃、雙叫吃）、習題本章節順序。
- 只用學過的觀念講解，遇到新觀念先提醒家長；**看不清楚或不確定時直接說，不要猜**。
- 學到新章節時，在對話補一句「這週開始練征子了」即可。

### 3. 用觸發詞切換情境

| 觸發詞 | AI 要做的事 |
| :--- | :--- |
| 檢查作業（附照片） | 先用兩三句話說明這頁在練什麼、家長怎麼講給孩子聽；再逐題判斷。判斷前**先數清楚相關棋塊各有幾口氣並指出空位位置**，方便家長核對。答錯說明錯在哪、正確位置；沒作答給參考答案。 |
| 引導訂正 | **先不揭曉答案**，給家長一到兩個問題去問孩子；想不出來再給提示，最後才說答案。 |
| 出題 | 依進度出 3～5 題，由簡單到難。9 路棋盤，橫向 A～I、縱向由下到上 1～9，用「C3」回答。出題前先數氣、確認只有一個正確答案且合法；先不顯示答案，等家長輸入孩子的回答再判斷。 |
| 家長模式／開始陪練 | 家長模式改用大人的說法討論觀念與教法；說「開始陪練」回到兒童老師角色。 |
| 練習紀錄 | 只有家長說了才整理：練過的觀念、常錯的地方、下次要加強什麼。開新對話時貼上，就能接著練。 |

- 好用的引導問句範例：「你下的這顆黑棋，自己有幾個鼻孔？」「白棋只能救一邊，它救了這顆，你要吃哪一顆？」
- 實際效果：看作業幫助最大，例如 AI 指出那一頁其實在練普通叫吃而不是雙叫吃，也抓出孩子下的黑棋自己只剩一口氣、反而會被吃掉。

### 4. 拍照與核對
- 正面拍、一次一頁、避開陰影和反光。
- AI 列出的空位，家長用手指數一次；對不上就重拍或問老師。
- AI 出的題目可能答案不只一個，或白棋其實逃得掉。有爭議時請 AI 重新列出各棋塊的氣與空位，家長跟著核對。

## 二、下集：用 Claude 成品做成 5 關小遊戲

起因：孩子對著棋盤圖說「C4」缺少動手感，於是請 Claude 做成可以用手指點棋盤的小遊戲，答對拿星星、答錯先給提示，全程不寫程式。

**事前設定**：Claude 設定 →「功能」→ 開啟「程式碼執行與檔案建立」（新版介面可能叫「建立及編輯檔案」）。要給家人或其他家長玩，再用成品的分享或發布選項取得連結（分享方案限制見 [[Claude 成品製作旅遊行程網站#一、免費版與 Pro 的差異]]）。

### 1. 共用基本指令（每關都先貼這段）
- **棋盤與操作**：9 路棋盤，橫排 A～I、直排 1～9，畫星位；直接點交叉點作答，按鈕和棋子要大到手指好點。
- **題目**：一共 5 題，由簡單到難，題目要求寫在棋盤上方。
- **對錯回饋**：答對顯示鼓勵、拿一顆星，並在棋盤標出這一步的結果；第一次答錯給一句提示再試；第二次答錯閃爍標出正確位置並說明原因，不給星。
- **說法**：用六歲孩子聽得懂的話，「氣」說成「鼻孔」，斜的不算。
- **檢查**：每題做好後**請用程式檢查**答案正確、那一步合法、符合這關的答對條件，通過才放進遊戲。
- **結束**：顯示總星數、可以再玩一次，並提供「這題重來」按鈕。
- **給家長**：在對話裡另外列出每題答案位置，試玩前先核對。

### 2. 五關與各關專用段落
關卡順序依兒童圍棋習題本前幾章：**數鼻孔 → 提吃 → 逃走 → 叫吃 → 雙叫吃**。

- **數鼻孔**（答案有好幾格，要另外寫判斷方式）：點對一格放小圓點，全部點完才算答對；重複點不算錯。點到斜角提示「斜斜的不算喔」，點到有棋子的位置提示「這格被佔住了，不是鼻孔」。完全沒點錯才給星；點錯 3 次閃爍標出還沒找到的鼻孔。題目從中間一顆棋（4 個鼻孔）、邊上、角落，排到被白棋擋住的一塊棋。
- **其他四關共用句型**：

```
這次練「＿＿」。
每題有＿＿，請孩子＿＿。
答對條件：＿＿。
答對時：＿＿。
答錯時，提示＿＿。
題目順序：從＿＿排到＿＿。
檢查：確認每題只有一格符合答對條件。
```

- **自己寫不出答對條件**：把圍棋觀念教學網頁的網址交給 Claude，請它整理「這個觀念怎樣算答對、孩子常犯什麼錯」再寫進規則；讀不到網頁就把文字貼上。

### 3. 試玩與修正
- 家長先玩一輪，不順就用一句話請 Claude 改，例如「第 4、5 題太難，換成跟第 2 題差不多難度」「多出兩題斜角的陷阱題」「孩子塞錯邊時，用動畫示範白棋怎麼逃走」。
- 即使要求用程式檢查，AI 出題還是可能錯；覺得怪就追問「第 3 題除了這格，還有沒有其他答案？請重新檢查。」
- 5 關都練過後，可以請 Claude 合併成「過關才能往下走」的闖關版。
- 平板或手機上用手指點最順手。

## 三、可以借用的做法

1. **觸發詞切換模式**：把一份專案指示拆成「檢查作業／引導訂正／出題／家長模式／練習紀錄」幾個情境，比每次重打長提示詞穩定。和 [[Claude Cowork 與 Agent Skill 實務]] 裡用專案或 Skill 固定工作方法是同一個思路。
2. **「先驗證再放進去」寫進指令**：要求 AI 用程式檢查每題的合法性與唯一解，再加上人工試玩，這兩層缺一不可。
3. **共用基本指令＋關卡專用段落**：先寫一段共用骨架，再用固定句型接上差異，方便擴充，也適用其他科目的練習遊戲。
4. **家長是最後一道核對**：和 [[Wordwall 與教育科技的 AI Agent 自動化實務]] 的段考出題一樣，AI 負責從 0 到 1，專業判斷與審題仍要靠人。
