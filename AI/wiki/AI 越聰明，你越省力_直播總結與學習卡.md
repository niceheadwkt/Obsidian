# AI 越聰明，你越省力：直播總結與精選學習卡

本頁整理 [[Claude 基本功與個人 AI 工作流實戰|三師爸 (Sense Bar)]] 於 2026-10-18 晚間直播〈AI 越聰明，你越省力〉之核心內容、技術架構與精選學習卡。

> [!IMPORTANT]
> **核心結論**：AI Agent 不是工具箱裡的「又一個」工具，而是你要學的「最後一個」AI 工具。當 Agent 接手你的電腦，所有工作都能在一個自然語言對話框裡一條龍交付完成。跨過這道分水嶺後，工作模式將徹底翻轉：**人類專注於定義專業要求與最終審核，工具的調用與操作交由機器全權執行**。

## 一、核心觀念與架構解析

### 1. 工具收斂的分水嶺本質
* **傳統模式 vs. Agent 模式**：
  * **傳統模式**：為了解決不同環節，需分別學習剪輯軟體、字幕軟體、簡報軟體、公式編輯器、排版工具或 ComfyUI 等介面，工具越學越多、繁瑣切換。
  * **Agent 模式**：所有操作與工具調用被抽象化並收斂至單一對話框，透過對話發出指令，Agent 自動調用各類命令列工具與手腳完成端到端產出。
* **經驗封裝與傳承**：將踩坑調試好的工作流封裝進 GitHub Repository（包含 `AGENTS.md` 藍圖規範），其他人只要指派自己的 Agent 讀取該 Repo，即可在本地直接重現整套高階工作流。

---

### 2. AI 工具三代演進路徑

| 世代 | 代表工具 | 核心技術與運作特徵 | 建議定位與策略 |
| :--- | :--- | :--- | :--- |
| **第一代：生成式 AI (Generative AI)** | Gemini、NotebookLM、ChatGPT Web | 僅在雲端生成文字或圖表，無本機手腳，無法碰觸本地系統。 | 僅適合簡單對話；面對複雜專案效率低落，建議果斷「棄守」。 |
| **第二代：AI Agent** | [[Claude]] (Claude Code)、Codex、[[AI Agent 與 AntiGravity 2.0 基礎入門\|AntiGravity]]、OpenCode | 具備執行環境、讀寫本地檔案、執行終端機命令、聯網搜尋與工具調用手腳。 | **當前主力**，能在單一對話框內完成端到端工作交付。 |
| **第三代：Agent Bot（代理人機器人）** | Dot（小巴）、GUACBOT | 具備專屬雲端虛擬電腦與長期記憶，關閉本機仍 24 小時在雲端自動化運轉。 | 可掛載雲端硬碟自主工作，或跨端遠端喚醒家中桌機執行任務。 |

> [!NOTE]
> 若不想每月支付額外高額月費（如 30 美金）訂閱雲端 Agent Bot，善用 **Remote Control** 遠端連線家中常駐開啟的桌機（如 Mac mini），其工作流與效益幾乎與 Agent Bot 無異。

### 3. 資安疑慮與本地 Agent 破局點（Strata 架構深度解析）
* **以雲建地**：無須手動研究繁瑣的本地環境建置與依賴項設定，直接叫雲端 Agent（如 Claude Code / Codex）去 GitHub 尋找專案並一步步在本地安裝好本地 Agent。
* **Strata 架構突破（GitHub：[Niko1221/Strata](https://github.com/Niko1221/Strata)）**：
  * **解決核心痛點**：過去 7B/14B 小模型智力不足無法勝任複雜 Agent 工作，而 125B 等級的大型 MoE（混合專家模型，如 *Qwen3.8-Flash-Next*）以往需企業級 80 GB 伺服器顯卡才能載入。
  * **分層異質卸載與動態專家快取 (Heterogeneous Offloading & Expert Caching)**：Strata 將龐大的專家層權重常駐於**主機系統記憶體（RAM，需 32 GB～64 GB）**，運算時僅將高頻使用的核心層與當前被激活的專家網路動態快取進 GPU 顯存。
  * **客製化 GPU Kernels 與極致量化**：搭配 GGUF / IQ 極端量化與優化的計算核心，大幅降低跨 PCIe 匯流排傳輸延遲，大幅提升 Prompt Prefill 與 Token 生成速度。
  * **硬體門檻降級**：成功讓一般消費級 **12 GB 顯存（VRAM）**的顯示卡（如 RTX 3060 12GB、RTX 4070、RTX 5070 等）即可流暢運行旗艦級 MoE 模型。
* **本地 Agent 串接端點**：
  * Strata 內建相容於 OpenAI 與 Anthropic API 格式的本地伺服器（例如 `http://127.0.0.1:8080/v1`）。
  * 外部 Agent（如 Claude Code、Zed、Cursor、OpenCode）只需將 `baseURL` 指向本地端點，即可離線調用本地千億大腦。
* **敏感資料離線分流**：處理學生個資、成績、學籍或校務未公開文件時，無縫切換至本地 Strata Agent 離線執行，杜絕雲端資安外洩風險。

## 二、五大高價值落地實戰場景

### 1. 全自動一條龍 AI 教學影音生成
* **零外部軟體介入**：不開剪輯軟體、不開字幕軟體，完全在對話框內完成。
* **標準流程**：
  1. 輸入主題與個人累積之專業知識庫。
  2. Agent 撰寫分鏡腳本，人類快速審核。
  3. Agent 自主調用程式碼生成動態圖表與幾何動畫解說。
  4. 整合個人人像與個人聲音模型合成影片。
* **成果與效益**：幾何與圖表動態解說比真人錄影更清楚直觀，三部教學影片累計近三萬次觀看。

### 2. Codex 對話框即時視覺化與互動教學
* **教材即時數位化**：直接讀取課本 PDF 或課綱教材圖片。
* **即時互動介面**：在 Codex 對話視窗內直接渲染具備拖拉、互動元件的視覺化介面（如數學「連比」概念）。
* **自適應學習反饋**：學生在對話框內作答，答錯時系統自動分步拆解概念引導，答對自動推進下一關卡，並可一鍵產出 HTML 互動簡報。

### 3. 數學科高難度非選題精準命題與排版（Claude Code）
* **高階認知層次出題**：依據教師專業提示精準出題，如「面積相同但周長不同的多項式分析題」、「直式除法係數全挖空反推題（考驗運作底層邏輯）」。
* **精準幾何圖形與排版**：自動產出嚴格對齊的角度與幾何圖形，自動排版成 B4 雙欄試卷與 Word/PDF 檔，解決過去方程式編輯器排版繁複之痛點。
* **專業不可替代性**：AI 負責出題與排版，但難易度控制、是否超綱與雙向細目表審題仍高度仰賴人類專業。

### 4. 紙本手寫非選題 AI 批改與引導（準確率 90%+）
* **紙本結合數位流程**：
  1. **學生端**：維持在紙本手寫完整計算歷程（保留原始思考脈絡）。
  2. **採集端**：交卷後使用 iPad 拍照上傳非選題。
  3. **AI 批改**：透過高精準度 OCR 辨識手寫筆跡，並沿著學生邏輯推導步驟批改。
  4. **回饋反饋**：AI 在試卷圖像上精準圈出錯誤步驟，並附上逐步訂正參考解析。
  5. **教師把關**：教師於後台抽查審核關鍵步驟即可快速確認成績。
* **實測驗證**：已累積驗證超過 200 餘題，非選題批閱準確率達 90% 以上，大幅解放批改勞務。

### 5. 跨設備 Google Drive 鏡像雙向同步架構
* **單一事實來源 (Single Source of Truth)**：選定一台常駐開機之主力桌機（如 PC 或 Mac mini）設定 Google Drive **「鏡像檔案（雙向同步）」**（本機實體硬碟一份，雲端硬碟一份）。
* **多端一致存取**：筆電、手機、外部 Agent（如 Dot 小巴）統一掛載至該 Google Drive 目錄，實現全設備隨時隨地無縫存取同套專案資料夾。

## 三、工具選型與配置策略

### 1. Claude Code 黃金四檔配置心法
Claude Code 為當前邏輯最嚴密、意圖理解最準確且 OCR 能力最強之首選。實務上建議固定使用以下「黃金四檔」，其餘檔次效益較低無需開啟：
1. **`Sonnet 5.5`（思考強度中）**：應對常規任務與日常輔助。
2. **`Sonnet 5.5`（思考強度高）**：應對中高等難度分析與代碼調試。
3. **`Opus 5.5`（思考強度中）**：高精準度、高品質成果交付。
4. **`Opus 5.5`（思考強度高）**：頂配極限難題、複雜系統架構規劃。

### 2. 工具分工與預算配置
* **工具分工**：
  * **Claude Code**：主力產出大腦（影音腳本、非選題命題、程式開發）。
  * **Codex**：日常視覺化互動介面與生圖。
  * **[[AI Agent 與 AntiGravity 2.0 基礎入門|AntiGravity]]**：日常校務/班務小助手；配合 Google One 附贈之 Colab 200 單位運算額度，能以低成本呼叫高階雲端算力。
* **100 美金（約 3300 台幣）月預算分配**：
  * 首選直接訂閱 **Claude Code**。
  * 家中配置一台開機常駐主機配合 Remote Control，性價比最高。
* **問題排查第一原則**：
  * 「不要問人，問你的 Agent」：遇到配置錯誤、Token 參數、Repo 安裝問題，第一時間直接拋給 Agent 進行分析與修正。

## 四、精選複習學習卡 (Study Cards)

### 學習卡 01：工具本質
* **Q：為什麼說 AI Agent 是你要學的「最後一個」AI 工具？**
* **A**：因為 Agent 具有接管電腦、調用各類軟體與終端機命令的能力。過去人類需要針對剪輯、排版、修圖分別學習不同工具軟體；學會 Agent 後，所有操作皆收斂至單一對話框，工作流從此完成統一整合。
* **關鍵筆記**：不用學軟體介面，用對話指揮手腳。

---

### 學習卡 02：AI 世代演進
* **Q：生成式 AI、AI Agent 與 Agent Bot 三者有何根本區別？**
* **A**：
  * **生成式 AI**（如 ChatGPT Web）：僅在雲端生成文字/圖表，無本地手腳。
  * **AI Agent**（如 Claude Code）：具備手腳，能在本地電腦讀寫檔案、執行指令、呼叫工具。
  * **Agent Bot**（如 Dot）：具備獨立雲端電腦與長期記憶，關閉本機仍能持續運作，並可跨端遙控本機。
* **關鍵筆記**：生成式 AI 提供答案，Agent 交付成果，Agent Bot 自主值班。

---

### 學習卡 03：資安與本地部署
* **Q：擔心雲端 AI 外洩敏感個資時，最高效的本地部署策略是什麼？**
* **A**：不要手動折騰繁瑣的環境建置，而是「用雲端 Agent 幫你架設本地 Agent」。遇到學生名冊、成績或商業機密時，切換至本機離線 Agent 執行。
* **關鍵筆記**：讓聰明的雲端大腦，替你在本地蓋好安全的保險庫。

---

### 學習卡 04：本地硬體門檻與 Strata 架構
* **Q：目前能讓消費級顯卡順暢跑動千億級本地 Agent 的關鍵架構「Strata」是什麼？原理為何？**
* **A**：Strata（GitHub: [Niko1221/Strata](https://github.com/Niko1221/Strata)）是一套專為消費級硬體設計的本地推理引擎。它透過「分層異質卸載（Heterogeneous Offloading）」將龐大的 MoE 專家權重保留在系統 RAM（32 GB～64 GB），僅在 12 GB 顯存的 GPU 中動態快取當前活躍的專家層，並提供本機相容 API 端點（`127.0.0.1:8080`），讓 Claude Code 等 Agent 能以完全離線、零隱私風險的方式調用千億旗艦大腦。
* **關鍵筆記**：MoE 動態專家快取突破顯存牆，12 GB VRAM 即可離線驅動旗艦 Agent。

---

### 學習卡 05：工作流封裝
* **Q：如何將自己優化過的高階 AI 工作流（如 AI 生成影音）無損分享給他人？**
* **A**：將所有踩坑經驗、結構規範與提示規則封裝至一個 GitHub Repository（包含 `AGENTS.md` 藍圖）。他人只需指派自己的 Agent 讀取該 Repo，即可在本地直接重現整套工作流。
* **關鍵筆記**：Repo 就是新時代的操作手冊，Agent 之間直接傳承經驗。

---

### 學習卡 06：AI 時代專業價值
* **Q：當 AI 能夠自動出題、排版與批改考卷時，人類專業工作者的核心價值何在？**
* **A**：核心價值在於「定義標準、給定邊界與最終審核」。AI 不會憑空知道良好的教學架構與認知層次；專業工作者透過指令引導題型層次、控制難易適中度與審核是否超綱，確保成果符合實務規範。
* **關鍵筆記**：AI 放大你的專業，而不是取代你的專業。

---

### 學習卡 07：紙本與數位整合批改
* **Q：數學非選題的 AI 自動化批改流程如何兼顧學生思考與閱卷效率？**
* **A**：學生維持在紙本上手寫完整推導步驟，交卷後透過 iPad 拍照上傳。AI 透過高精準度 OCR 辨識筆跡並依邏輯逐步批閱，圈出錯誤位置並提供訂正解析；教師僅需抽查關鍵爭議點即可確認成績。
* **關鍵筆記**：手寫保留思考脈絡，AI 承擔批改勞務，教師把關最終評分。

---

### 學習卡 08：雲端硬碟架構
* **Q：跨手機、筆電與多個 Agent 協作時，最佳的檔案同步架構為何？**
* **A**：選定一台常駐桌機開啟 Google Drive 的「鏡像檔案（雙向同步）」模式；其餘筆電、手機與雲端 Agent Bot 統一指向該雲端目錄，實現跨設備單一事實來源（Single Source of Truth）。
* **關鍵筆記**：本機鏡像實體檔案，全設備統一掛載雲端目錄。

---

### 學習卡 09：Claude Code 四檔設定
* **Q：Claude Code 官方推薦使用的「黃金四檔」配置為何？**
* **A**：
  1. `Sonnet 5.5`（思考強度中）：常規與日常工作。
  2. `Sonnet 5.5`（思考強度高）：中高複雜度分析。
  3. `Opus 5.5`（思考強度中）：嚴謹高標準交付。
  4. `Opus 5.5`（思考強度高）：頂階複雜度專案。
  其餘檔次皆不符效益，無需開啟。
* **關鍵筆記**：二模型乘二強度，精準鎖定高性價比產出。

---

### 學習卡 10：問題解決心態
* **Q：面對安裝失敗、參數設定或環境整合問題時，正確的提問對象是誰？**
* **A**：不要第一時間上網問人或發訊息求助他人，而是直接將問題與錯誤訊息拋給你的 AI Agent，讓 Agent 自行分析 GitHub 專案、測試環境並提供具體修復方案。
* **關鍵筆記**：跨過 Agent 分水嶺的第一步，就是學會「先問你的 Agent」。
