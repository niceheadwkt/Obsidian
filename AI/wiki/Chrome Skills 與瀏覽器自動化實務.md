# Chrome Skills 與瀏覽器自動化實務

本頁面介紹 2026 年 Google 瀏覽器推出的原生隱藏自動化功能 **Chrome Skills**，並與現代網頁自動化測試及爬蟲工具 **Playwright** 進行技術對比，打通瀏覽器端「零輸入自動化」與「程式驅動自動化」的實務流程。

---

## 1. 2026 Chrome Skills 原生自動化技能

**Chrome Skills** 是 Google 在 Chrome 瀏覽器右上角「問問 Gemini」側邊欄中釋出的原生自動化功能。它允許使用者將繁雜的 Prompt 封裝為瀏覽器的「原生快捷按鈕」，大幅降低上班族的無效複製貼上操作。

### 1.1 環境開啟與暴力解法 (Setup)
*   **第一步：開啟「問問 Gemini」側邊欄**
    *   於 Chrome 右上角點擊側邊欄圖示，並切換至「問問 Gemini」。
    *   *暴力破解法*：若找不到，可直接在網址列輸入 `chrome://layout-sidebar.gps` (或依版本而定) 以強制調出。
*   **第二步：開啟隱藏實驗開關 (Flags)**
    *   在網址列輸入 `chrome://flags`。
    *   搜尋 `Skills` 相關選項（如 `Enable Ask Gemini Skills`），將其切換為 `Enabled` 並重啟瀏覽器。
*   **第三步：進入技能管理中心**
    *   在網址列輸入 `chrome://skills/`。
    *   點擊「+ 新增」，在「指令 (Prompt)」中填入後端封裝提示詞，並定義技能名稱（如 `/行動清單`）。

### 1.2 Skills 封裝架構與指令軍火庫
在 `chrome://skills/` 中，可透過定義角色與格式，將常用的商務任務封裝：

| 技能名稱 (快捷指令) | 角色與核心指令 | 實戰應用模式 |
| :--- | :--- | :--- |
| **會議行動清單 (`/行動清單`)** | 提煉會議逐字稿中的決策點、待辦事項、負責人與預計期限，使用 Markdown 輸出。 | `@會議分頁 /行動清單` |
| **競品數據對比 (`/數據對比`)** | 對比競品規格與我方產品，輸出對比表格（優勢/劣勢/改進建議）。 | `@競品官網 /數據對比` |
| **長篇研究摘要 (`/深度摘要`)** | 分析研究報告 PDF，總結 5 大趨勢，並給予【趨勢標題/解析/建議】。 | `對應PDF分頁 /深度摘要` |
| **法律條款審核 (`/風險審核`)** | 對比合約與我方標準範本，輸出風險對照表（條文/風險點/風險等級）。 | `@合約草稿 /風險審核` |
| **粉絲留言回覆 (`/回覆粉絲`)** | 口語溫暖回覆留言，附帶 3 個 Emoji，結尾包含引導互動的反問句。 | `@留言截圖分頁 /回覆粉絲` |
| **影片縮圖建議 (`/縮圖建議`)** | 根據腳本，提供 3 組 CTR 點擊率高的縮圖構圖方案（背景/主體/文案）。 | `@腳本分頁 /縮圖建議` |

## 2. Playwright 網頁自動化

與 Chrome Skills 的「AI 閱讀與零輸入」不同，**Playwright** 是微軟開發的開源程式驅動瀏覽器自動化工具，旨在代替人類的手腳在瀏覽器中進行精確操作。

### 2.1 核心功能與應用場景
*   **端到端測試 (E2E Testing)**：自動模擬使用者在網頁上的所有交互路徑（如登入、加入購物車、結帳），用以驗證前端功能是否正常。
*   **高級爬蟲與動態渲染**：傳統爬蟲（如 BeautifulSoup）無法處理 React/Vue 等框架動態渲染的 DOM。Playwright 可等待 JavaScript 完整載入，並解析複雜網頁。
*   **模擬複雜使用者行為**：模擬真實滑鼠點擊、鍵盤輸入、拖拽、上傳檔案，甚至繞過簡單的反爬蟲機制。
*   **RPA 自動化**：定時執行登入後台系統、下載報表或搶票簽到等例行公事。

## 3. 技術對比：AI 上網搜尋 vs. Playwright 自動化

| 特性/功能 | AI 上網搜尋 (Web Search) | Playwright 自動化 |
| :--- | :--- | :--- |
| **技術本質** | AI 的資訊檢索擴充功能 | 程式控制的無頭/有頭瀏覽器 |
| **運作方式** | AI 背後透過搜尋引擎讀取網頁摘要與片段 | 實體開啟 Chrome/Safari 執行腳本操作 |
| **核心優勢** | 快速解答、打破大模型知識時間限制 | 完美互動（點擊、登入、輸入、截圖、匯出 PDF） |
| **局限性** | 無法實際執行點擊按鈕、登入或填寫表單 | 需要編寫程式碼 (Python/JS)，無法自主進行推理 |

## 4. 總結
*   **Chrome Skills** 適合非技術人員或日常辦公中，針對目前頁面資料進行「快速分析、摘要與內容加工」。
*   **Playwright** 則是工程師在進行「爬蟲開發、自動化測試與 RPA 流程重塑」時的首選武器。
