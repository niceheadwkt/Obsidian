# AI 影片角色資產製作：照片、聲音與生圖模型選擇

三師爸 Sense Bar 2026-10-10 直播（約 1 小時 21 分），示範怎麼替 AI 影片建立一個可以重複使用的角色：拍照、錄音、用兩種生圖模型做角色資產並比較，再用三種語音模型複製聲音，最後讓新角色演一段 10 秒的對手戲。全程在 Agent 對話裡完成，不開 ComfyUI。此影片 YouTube 字幕已停用，raw 逐字稿是 2026-11-23 以 Whisper 自動辨識產生，人名與工具名可能有錯字（例如新角色名稱「少姐／少傑」辨識不一致）。

**一句話重點**：角色圖與聲音先定稿，之後一句話就能叫角色演戲

## 一、真人角色要準備什麼

| 資產 | 做法 | 重點 |
|---|---|---|
| 照片 | 約 7 張：正臉、左右 45 度、左右 90 度側臉、仰角 45 度、俯角 45 度，再加一張笑容 | 角度齊全，角色轉頭、做動作時才像本人；要生氣等表情可再補 |
| 聲音 | 用較好的麥克風錄自然講話，**至少 15 秒**，內容涵蓋各種發音 | 少於 15 秒聲音會不像；可請 Agent 給一段發音多樣的稿子來唸 |
| 設定 | 把照片路徑給 Agent，補上年齡、職業、服裝特徵（例：30 多歲體育老師、脖子掛哨子、綁馬尾） | 設定寫進專案的 CLAUDE.md／AGENTS.md，Agent 才知道每個角色適合演什麼 |

- **一定要取得本人同意**：講者使用家人照片前已取得授權並限定直播使用；拿真人做角色都要先經過對方同意。
- 不用真人也可以：直接請 Agent 隨機創造一個新角色並產出角色資產。
- 角色資產包含定裝照（正面、45 度、90 度側面、背面）與表情表（吹哨、生氣、笑等），存在專案資料夾；角色定好後，下次只要說角色名字，Agent 就會自動套用圖片和聲音。

## 二、生圖模型：OpenAI Image 2.5 與千問 Image 2.1

| 項目 | OpenAI Image 2.5 | 千問 Image 2.1（本機） |
|---|---|---|
| 排名 | 講者認為目前第一，Nano Banana 2.1 也沒贏過 | 本機模型的天花板（講者估計整體約第五） |
| 費用 | API 每張約台幣零點零幾元，60 秒影片的首幀約數元到十幾元 | 免費，有顯示卡就能跑，約 1 分鐘一張 |
| 像不像本人 | 給參考圖就很準，**不用訓練 LoRA** | 直接生不像本人，**要訓練人物 LoRA**（repo 內附 AI Tools，訓練到約 800 步以上較準） |
| 設定陷阱 | 品質設 Low 或 Medium 即可，影片最高約 768p，圖太精細沒意義 | 預設 25 步品質很差，要改成 **40 步**（50 步差不多但較慢）；改圖要用 Image Edit |

- **圖片品質決定影片品質**：講者自己做影片一律用 Image 2.5 當首幀；想完全免費就用千問並訓練 LoRA。
- LoRA 分兩種：**人物 LoRA**（固定人、動作可換）與**動作 LoRA**（固定動作、人可換）。只有本機生圖才需要訓練。
- Codex 的 ImageGen 技能吃訂閱額度、不另付費但較慢；接 OpenAI API Key 可一次平行生十幾張，60 秒影片約需 12 張首幀，看速度需求取捨。

## 三、語音模型：三選一還是混用

| 模型 | 優點 | 缺點 |
|---|---|---|
| Breeze TTS | — | 不可商用，影片要營利就不能用 |
| VoxCPM2 | 音質最好、情緒表現佳、命中率高（約兩段中一段） | 大陸模型，有大陸腔，部分字念法不同（例：「柏油路」的柏） |
| BreezyVoice | 台灣腔、字念得對、可用注音修正 | 命中率低，可能生五段才有一段可用 |

- 講者的選擇：**平常配音用 BreezyVoice 定稿**，需要很生氣、很著急等特殊語氣時改用 VoxCPM2 當備用。
- 「命中率」靠 Agent 補：每句生成多段候選，用語音辨識和台灣腔分數自動挑；人只需要再聽一遍，指出「第幾秒哪個字腔調不對」讓它重生，通常兩三輪就正確。
- AI 先做完 80～90% 的審核，最後 5～10% 仍要人審。

## 四、影片生成的基本邏輯

- **先生成聲音，再生成影片**：影片模型依台詞與聲音對嘴型；讓影片模型自己出聲成本更高。
- **一段 5～10 秒**：長片段後段容易壞，重生成本高。用前一段的**尾幀**當下一段的首幀，接起來看起來就是連續動作；每段各自抽到合格為止。
- **GPU 一次只做一件事**：工作流依序「生聲音 → 生圖 → 生影片」，每階段結束釋放顯示記憶體再載入下一個模型，所以跑影片時這台電腦不能同時做別的本機 AI。
- **丟著跑**：工作流建好後一句話下指令就去睡覺或上班，回來審片；修改一次講完。講者示範的「唐太宗教英文」「連假段考不塞車」都是一句話生成、最多修一次。

## 五、硬體建議

- 本機生成影片門檻是 **16GB VRAM**；12GB 能跑但很慢，且只能用量化模型、品質較差。
- 性價比：5060 Ti 16G（約 2.4 萬）是甜蜜點，5070 Ti、5080 較快；5090（32GB）溢價太高，約快兩倍但品質相同。
- 建議裝在家裡的桌機，不適合筆電。

## 六、自媒體角色的建議

講者建議做自媒體或個人品牌時**用自己當角色**：觀眾認得的是本人，虛擬角色要長期維護，且實體活動時無法出場。

> [!NOTE]
> 直播後段約 15 分鐘為講者談第一線教師授課負擔與寒暑假輔導課，與主題無關，本頁未納入。

## 我可以怎麼用

- **教育訓練影片的固定講師**：替 EA 等系統教學影片建一個固定角色（圖＋聲音），之後每支影片都由同一個角色講解，觀感一致，也省下每次重做的時間。
- **聲音選擇照用途分**：內部教學可用 BreezyVoice（台灣腔、可商用）；要對外營利時避開 Breeze TTS。這也是 [[claude-motion-explainer 科普解說動畫技能]] 實際使用的模型。
- **本機模型先檢查預設參數**：千問 25 步預設品質差、改 40 步就正常；評估任何本機模型前先確認參數，避免錯怪工具。
- **「多生幾份、程式先篩、人最後聽」**：語音命中率低時，用自動挑選補足；這個做法也適用 AI 產生 SQL 或文件後的自動檢查。
- **用到真人肖像或聲音前先取得同意**，並限定使用範圍。
