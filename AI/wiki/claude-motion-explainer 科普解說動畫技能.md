# claude-motion-explainer 科普解說動畫技能

三師爸 Sense Bar 2026-10-18 YouTube 直播（約 27 分鐘），現場讓 Claude Code 做一支科普解說動畫，再把整套能力打包成公開技能 `claude-motion-explainer`（`https://github.com/mathruffian-dot/claude-motion-explainer`），讓 Codex、OpenCode、Antigravity 也能使用。逐字稿為語音辨識，專有名詞已依原意修正。

**一句話重點**：Claude Code 做動畫的本事打包成技能，別家也能用

## 一、為什麼要做這個技能

- 講者過去用 HyperFrames 或 Remotion 寫網頁動畫再壓成影片（見 [[Antigravity 與 Remotion 影片生成實務]]）；現在模型本身做動畫已經很強。
- 實測發現 **Claude Code 做動畫特別強、其他家較弱**（模型與 harness 都有影響）。目標是把 Claude Code 的做法整合成一個大技能，讓用別家 Agent 的老師也能做出不錯的解說動畫。
- 定位是**教學、科普、原理解說動畫**，不是 AI 生成影片，也不是 Three.js 那類炫技。
- 一句話流程：AI 上網查資料 → 寫腳本 → 配旁白 → 產生動畫影片。

## 二、實作案例：用國中理化解說特斯拉新款 Roadster

提示：上網找特斯拉 10 月 15 日發表的新款 Roadster（可倒掛、短暫滯空、加速極快），做一支解說神奇配備原理的動畫。成品內容：

| 配備 | 原理 | 動畫中的數字 |
|------|------|--------------|
| 倒掛 | 車底四具風扇抽走空氣、裙邊封住縫隙，下方氣壓變低，外面空氣把車壓向路面（壓力差） | 車重約 1,700 kg、車底約 4 m²，下方只要比外面少約 4% 氣壓就不會掉 |
| 滯空 | SpaceX 冷氣體推進器把高壓空氣往下噴，車子被往上推（作用力與反作用力）；氣瓶只撐幾秒，只能跳一下控制姿態 | — |
| 0.81 秒加速 | 輪胎推力取決於摩擦力；吸地風扇增加正向力讓摩擦力變大，後方推進器再直接把車往前推 | 頂級輪胎約 1.5 G，但需要 3.4 G |

講者評價：內容與動畫解說非常清楚，適合知識類課程；視覺（配色）可以再調。

## 三、現場修改技能

1. **字幕改粗體**。
2. **三色主題**：原本只有藍色太單調，改成像簡報設計一樣讓使用者指定**主色、背景色、強調色**；講者自己的習慣是黑底白字、橘色重點。
3. **可加圖片**：純程式碼動畫之外，可接生圖 API 或 Codex CLI 的 Image Gen，讓部分畫面用圖片。
4. **可嵌影片**：在解說過程中嵌入實際影片（例如 Roadster 起飛畫面）。
5. **語音合成選項**：講者本機用 **BreezyVoice**（聯發科研究團隊＋台大，開源、台灣腔、可用參考音合成自己的聲音、可商用；筆電 4080 12G 也要跑一下）；電腦跑不動的人改用 **Edge TTS**（效能需求最低），已寫進 repo 說明。也可以改接 Gemini 等雲端 TTS，但需要 API Key。

   > [!NOTE] 已確認（2026-11-23）
   > 直播口述為「Breeze TTS」，經使用者確認實際使用的是 **BreezyVoice**（Hugging Face 標示 Apache-2.0，可商用）。注意不要和名稱相近的 **Breeze TTS 2** 混淆：後者由另一家公司 BreezeBlue 開發，權重為非商用授權，自己架起來生成的聲音也不能營利（見 [[MiniMax-H3 本機 AI 短片製作原理與踩坑]]）。BreezyVoice 部分程式衍生自 CosyVoice，正式營利前仍建議再看一次 GitHub `mtkresearch/BreezyVoice` 的完整授權。
6. 命名刻意用 `claude-motion-explainer` 方便被搜尋。

應用想像：數學老師做「畢氏定理」解說（連同故事與由來）；物理、數學原理特別適合；英文、國文等文組科目則多加圖片與影片讓畫面豐富。

## 四、加碼：用 Colab 加速 AI 影片

- 講者有兩個 Google AI Pro 帳號（一個給家人用），每月共 **400 單位 Colab**；另購約 10 美元（約 320 元台幣）100 單位。
- **兩台 Colab＋自己的電腦同時生成**，AI 影片可達四倍速：一支兩三分鐘的 AI 影片原本約 3 小時，全速可在 1 小時內完成。Agent 用技能把工作丟到 Colab，做好再下載回本機合成，人不必顧在電腦前。
- **隱私資料**：可以讓雲端 Agent 指揮 Colab 與本地模型處理敏感資料，但要和 Agent 討論好機制，確保雲端 Agent 讀不到敏感內容；做得到但較難。
- 講者認為「用 Colab 等於隨時可調用一台六十萬的主機」，暫時不必買桌機。

## 五、直播中的觀點與閒聊

- **對話就是介面**：講者的做法是 skill＋專案＋對話；做 UI 讓人點選限制多、效率低，只有上課或固定工作流才值得做介面。
- **本地 Agent 的定位**：只有處理隱私資料（例如通報建檔）或需要巨量 token 時才需要；一般人每月 20 美元方案就夠用。
- **模型差距會被追平**：Opus 5.5 寫程式做動畫特別強，但各家進步很快；次一級模型（Sonnet 5.5、DeepSeek Flash、GLM Flash 等）日常使用已足夠。
- **當天的工具消息**（講者口述，未查證）：Antigravity 加入 Gemini 4 Argon，只有週額度、沒有 5 小時額度，且需個人付費版（教育版、贈送的 Pro 沒有）；Gemini 桌面版把 Spark 整合成「任務」，在雲端執行、電腦不必開著，但不能做需要本機的工作；DeepSeek V4.1 Flash 推出 1017 版（同架構、加資料重新訓練）。

## 我可以怎麼用

- **ERP 教學動畫**：新功能上線說明、簽核流程、批次排程的運作原理，都可以用這個技能做 1～2 分鐘解說動畫，給使用者看比文字說明好懂；腳本先請 Agent 依規格書寫，人審過再生成。
- **配音沿用現有設定**：全域規則已用 Edge TTS（`zh-TW-YunJheNeural`）做語音回覆，動畫旁白可直接用同一套；要用自己的聲音再考慮 BreezyVoice 或 [[AI 語音複製與 VoxCPM2 本地部署]]。
- **三色主題統一視覺**：和 [[HTML 簡報：AI Agent 時代的教學簡報完全體]] 共用同一組主色、背景色、強調色，簡報與動畫風格一致。
- **算力不夠時用 Colab**：Google One 附的 Colab 單位可以拿來跑重的生成工作；ERP 或公司資料不要送進 Colab 或雲端 Agent。
- **「先做順再打包」的另一個實例**：先手動做一支、確認品質，再請 Agent 打包成技能並推上 GitHub（呼應 [[Claude Cowork 與 Agent Skill 實務]]）。
