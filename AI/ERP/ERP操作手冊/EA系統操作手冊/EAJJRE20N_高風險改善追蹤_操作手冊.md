## 一、作業概要

【風險評估】(EAJJRE00N) B 表中風險等級為 **1、2（高風險）** 的項目，必須在本作業擬定改善措施、追蹤改善進度並經主管簽核。每個高風險項目、每個改善版次各有一份高風險文件（高風險文號）。

| 項目 | 說明 |
|---|---|
| 適用對象 | 風險評估 B 表中風險等級 1、2 的項目 |
| 操作人員 | **該風險評估的評估人（建立人）**；其他人只能查詢 |
| 簽核主管 | 依【簽核主管】頁籤設定 |
| 前提 | 該風險評估必須已**簽核完成**，才可執行高風險作業 |
| 完成條件 | 已執行【完工評估】且高風險文件**簽核完成** |

### 1.1 整體流程

```
風險評估簽核完成
  → 【預估評估】（擬定改善措施、預估效果、預估完工日，產生高風險文號）
  → 【送簽】 → 主管【核准】／【退回】
  → 改善期間：需要延後就【延期】並送簽
  → 改善完成：【完工評估】（填實際完工日、實際評估結果）
  → 【送簽】 → 主管【核准】 → 改善完成
```

### 1.2 改善進度狀態

| 狀態代碼 | 改善進度 | 說明 |
|---|---|---|
| （空白） | 尚未預估評估 | 尚無改善措施資料 |
| 40 | 預估評估 | 已擬定改善措施及預估完工日 |
| 20 | 延期 | 已延後預估完工日 |
| 30 | 完工評估 | 已完工並完成實際評估 |

畫面「文件狀態/改善進度」欄同時顯示文件簽核狀態（發文者暫存、簽核中、簽核完成等）與改善進度。

## 四、按鈕功能一覽

按鈕依「改善進度」與「文件狀態」顯示，**只有評估人（建立人）看得到維護按鈕**：

| 改善進度 | 文件為發文者暫存／退回 | 文件簽核完成 | 文件簽核中 |
|---|---|---|---|
| 尚未預估評估 | 預估評估 | — | — |
| 40 預估評估 | 修改、延期、完工評估、送簽 | 延期、完工評估 | 評估人：強制取回；簽核主管：核准、退回 |
| 20 延期 | 修改、完工評估、送簽 | 送簽 | 同上 |
| 30 完工評估 | 修改、延期、送簽 | 送簽（僅限上次簽核後又有異動） | 同上 |

| 按鈕 | 說明 |
|---|---|
| 預估評估 | 擬定改善措施，產生高風險文號（見 5.1） |
| 修改 | 修改預估評估、完工評估或延期後尚未送簽的資料（見 5.2） |

| 刪除、轉WD | 限系統管理者 |

所有按鈕執行前都會跳出確認視窗。

## 五、操作步驟

### 5.1 預估評估

1. 查詢出高風險項目（改善進度空白）。
2. 輸入改善措施：**取消及代替措施、工程控制改善、管理控制改善、個人防護具改善**（皆必填）。
3. 在「預估效果」欄選擇改善後預估的暴露頻率、發生機率、嚴重度。
4. 輸入**預估完工日**。
5. 按【預估評估】→ 確認。

系統動作：
- 改善版次＝今天，改善進度＝40，風險等級依預估效果計算。
- 產生高風險文號，文件狀態為發文者暫存。
- 實際評估日記為今天，歷程記載「yyyy/mm/dd【預估評估】完成!」。

檢查規則：
- 預估完工日不可空白，且不可小於今天。
- 改善版次（今天）不可小於目前最新的改善版次。
- 預估完工日不可小於目前最新的預估完工日。

### 5.2 修改

執行預估評估、完工評估或延期後、尚未送簽前（文件為發文者暫存或被退回），可修改改善措施、風險值及日期。改善措施四個欄位仍為必填。歷程會新增一筆「原狀態＋U」的修改紀錄。

### 5.3 延期

改善無法在預估完工日前完成時使用。

1. 將**預估完工日**改為新的日期。
2. **實際完工日**保持空白。
3. 輸入**預估評估日**、**完工/延期說明**。
4. 按【延期】→ 確認。

檢查規則：
- 新預估完工日必須大於今天，且大於原預估完工日。
- 預估評估日必須大於或等於今天。
- 實際完工日必須空白。
- 完工/延期說明不可空白。

完成後改善進度＝20，歷程記載「延期至 yyyy/mm/dd 說明」。延期後請送簽。

### 5.4 完工評估

改善完成後使用。

1. **預估完工日**保持原日期（不可修改）。
2. 輸入**實際完工日**、**預估評估日**、**完工/延期說明**。
3. 在「實際評估」欄選擇完工後實際的暴露頻率、發生機率、嚴重度。
4. 按【完工評估】→ 確認。

檢查規則：
- 預估完工日必須等於原預估完工日。
- 實際完工日不可空白，且必須小於或等於今天。
- 預估評估日必須大於或等於今天。
- 完工/延期說明不可空白。

完成後改善進度＝30，實際評估的風險等級由系統計算，歷程記載「yyyy/mm/dd 完工! 說明」。完工評估後請送簽，**簽核完成即改善完成**。

### 5.5 送簽、核准、退回

1. 至【簽核主管】頁籤設定簽核主管。
2. 回【高風險追蹤改善】頁籤，可在【加註意見】輸入說明，按【送簽】→ 確認。
3. 簽核主管開啟文件後按【核准】或【退回】；**按【退回】前必須在【加註意見】輸入退回原因**，空白時系統會提示並不送出。
4. 評估人可在簽核中按【強制取回】收回文件。

簽核完成後：
- 預估評估（40）簽核完成：可再執行【延期】或【完工評估】。
- 延期（20）簽核完成：可再送簽。
- 完工評估（30）簽核完成：改善完成；之後若再有異動（異動時間晚於上次簽核），才可再次送簽，避免重複送審。

## 六、無法執行高風險異動

畫面按鈕旁出現紅底大字「**現已無法執行高風險異動**」時，表示本項目不可再異動，所有維護按鈕都不會出現。滑鼠移到紅字上可看到原因：

| 原因 | 說明／處理 |
|---|---|
| 此文件於風險評估維護尚未簽核完成! | 風險評估尚未簽核完成，請先完成風險評估簽核 |
| 此風險內容非高風險等級(1、2)! | B 表該項目已不是高風險 |
| 此高風險項目已於新版風險評估(○○)核准時移轉，請至新版處理，本項目不可再異動! | 本項目已移轉到新版風險評估，請用新版的風險評估文號查詢處理 |
| 此非最新高風險改善措施預估資料!最新之改善版次為○○，而目前為○○ | 查到的是舊改善版次，請查詢最新版次 |
| 此高風險改善版次(○○)歸屬於截止設定日(○○)前資料，不可再異動! | 改善版次在系統參數 EA0013 `HriskUnExe`（截止設定日）之前（含當天） |
| 查無此 TBEAWORKDOC／TBEARE03／TBEARE04… | 資料不完整，請洽系統管理者 |

## 七、由新版風險評估自動移轉的高風險項目

部門以【新版複製】建立新版風險評估時，尚未完工或尚未簽核完成的高風險項目（B 表原始依據為 HC），會在**新版風險評估簽核完成時自動移轉**到新版：

1. 系統複製原高風險文件的異動歷程，以核准日為改善版次，依原改善措施、預估效果及預估完工日自動執行【預估評估】，產生**新的高風險文號**（發文者暫存，發文者為新版評估人）。
2. 歷程記載「【預估評估】完成!（由高風險文號 ○○ 移轉）」；原預估完工日已過期時沿用原日期並註記逾期，請評估人用【修改】或【延期】調整日期。
3. 評估人會收到 DW 待辦訊息，連結可開啟新版風險評估。
4. **原高風險文號鎖定**，不可再異動（見第六節）。
5. 以下情況不移轉：新版已改成風險等級 3 以上、原文件已完工評估且簽核完成、新版該項目已有高風險資料。

評估人收到通知後，請至本作業查詢新版的項目，確認內容並【送簽】，之後依一般流程追蹤。

## 八、高風險未完成通知

系統排程定期寄送「高風險追蹤改善未完成案件清單」給相關部門的股長、課長、廠處長及工安負責人（附 CSV 檔）。清單規則：
- 每個部門只列最新一版風險評估的高風險項目，同一項目只列最新改善版。
- 已完工評估且高風險文件簽核完成的項目不列入。
- 欄位：評估原因代碼、部門、評估人、狀態、製程、作業、序號、風險等級、高風險文號。
- 狀態：尚無資料、待預估評估、已預估評估待完工、完工延期中、已完工評估簽核中、退回待重新評估、風險評估核准後移轉等。

## 九、常見問題

| 問題 | 說明 |
|---|---|
| 看不到任何維護按鈕 | 只有評估人（建立人）可維護；或出現「現已無法執行高風險異動」（見第六節） |
| 「非建立人不可【預估評估】!」等訊息 | 請由該風險評估的評估人操作 |
| 預估完工日不可小於今日 | 預估完工日請填今天以後的日期 |
| 延期時「實際完工日須空白」 | 延期不可填實際完工日，請清空 |
| 完工評估時「新預估完工日應等於舊預估完工日」 | 完工評估不可改預估完工日，請改回原日期 |
| 完工評估簽核完成後無法再送簽 | 沒有新的異動就不需再送簽 |
| 舊高風險文號被鎖住 | 已移轉到新版風險評估，請改查新版（見第七節） |
| 風險評估 B 表的【高風險追蹤改善】頁籤不能修改 | 該頁籤僅供查詢，請在本作業維護 |
| 按【退回】沒有反應，提示欄位不可空白 | 退回時加註意見必填，請輸入退回原因 |
| 說明文件不能上傳 | 只有系統管理者可上傳，其他人只能下載 |
