# (EAJJBATCHJOB) 附件檔案下線機制　操作手冊

## 一、功能說明

本作業用來**清理年代久遠的上傳附件**，釋放伺服器空間。可處理兩種來源的附件：

| 來源 | 說明 | 對應資料表 |
|---|---|---|
| ZP 共用上傳 | 各系統畫面用「檔案上傳」元件上傳的附件（例如 EA 安環文件、MP 請購單附件） | `DB.TBZP0100` |
| DR 文件管理 | 透過 DR 文件管理上傳的附件（例如物料驗收、電子審規、信用狀申請） | `DB.TBDRDC3` |

另外提供【檔案連結】功能，把每個附件對應回「原本是哪張單、哪個畫面上傳的」，刪除前可以先點連結回原單確認，避免刪錯。

- 資訊代碼：`EAJJBATCHJOB`（附件檔案下線機制）
- 使用權限：授權群組 `INFO_EAJJBATCHJOB_AUTH`，沒有權限的人進不了本作業。

> ⚠️ **本作業的【刪除】會直接刪掉伺服器上的實體檔案，按下去不會再跳確認視窗，刪除後無法從系統還原。** 操作前請先確認該附件已超過保存年限，且不再需要。

## 二、畫面架構

進入作業後，畫面有三個頁籤：

| 頁籤 | 用途 |
|---|---|
| **ZP附件檔案** | 依系統別與年限，查出很久以前上傳的 ZP 附件，勾選後刪除。 |
| **DR附件檔案** | 依文件資訊關鍵字，查出 DR 文件管理的附件，勾選後刪除。 |
| **檔案連結** | 建立或查詢「附件 ↔ 原始單據畫面」的對照，讓前兩個頁籤的【超連結】欄可以點回原單。 |

建議的作業順序見「**六、建議作業流程**」。

## 三、【ZP附件檔案】頁籤

### 步驟 1：查詢

1. **系統別**：下拉選單選擇系統（**必選**）。

   | 代碼 | 系統 |
   |---|---|
   | EA | 安環績效管理系統 |
   | IN | 物料庫存管理系統 |
   | MP | 採購管理系統 |
   | MT | 進口運輸管理系統 |
   | ZM | 資訊需求管理 |

2. **年限**：選擇「1 年前」～「7 年前」（**必選**）。例如選「5 年前」，會查出**上傳日期在今天往前推 5 年（含）以前的全部附件**。注意是「N 年以前全部」，不是「剛好 N 年前那一年」；選「1 年前」會連 5 年、10 年前的舊檔一起查出來。
3. 按【**查詢**】。

- 系統別或年限任一沒選，訊息欄會顯示「歡迎使用上傳附件檔案批次維護作業」，不會查出資料。
- 只會列出**尚未刪除**的附件，依附件代碼、檔案代碼排序（**不是依上傳時間排序**，所以不同年份的檔案會混在一起），**一次最多顯示 1,000 筆**。超過 1,000 筆時，刪除一批後再查詢，就會帶出下一批。
- 查無資料時，訊息欄顯示「查詢成功...->無上傳檔案資料」。

### 步驟 2：確認清單內容

| 欄位 | 說明 |
|---|---|
| 核取方塊 | 勾選要刪除的檔案；表頭核取方塊可全選／取消全選。 |
| 檔案代碼 | 檔案在系統內的唯一編號（fileHandle）。 |
| 檔案名稱 | 原始檔名與副檔名。 |
| 同附件代碼檔案 | 同一筆單據（同一個附件代碼）底下的所有附件，可直接點開下載內容確認。 |
| 超連結 | 點下去會開啟**原本上傳這個附件的單據畫面**（例如事故報告、請購單）。這欄要先在【檔案連結】頁籤建立過對照才會出現，沒建立的會是空白。 |
| 上傳人員 | 工號與姓名。 |
| 上傳時間 | 上傳日期時間。 |

刪除前，建議透過「同附件代碼檔案」或「超連結」抽查內容，確認已無保存必要。

### 畫面示意

上圖為正式機實際畫面：系統別選「EA 安環績效管理系統」、年限選「1 年前」查詢的結果。因為「1 年前」包含一年以前的全部附件，畫面上出現 2018～2022 年的檔案是正常的；列表依附件代碼排序，所以年份不是由新到舊排列。「同附件代碼檔案」欄後面括號內的數字，是同一筆單據底下的附件個數，例如第 1～6 列同屬一筆單據，共 6 個附件。「超連結」欄目前是空白，表示這些附件還沒建立檔案連結（見第五節）。**灰色色塊為上傳人員的工號姓名，已事後遮蔽。**

### 步驟 3：刪除

1. 勾選要刪除的檔案（可複選）。
2. 按【**刪除**】。

系統會對每個勾選的檔案：

- 刪除伺服器上的實體檔案。
- 在 `DB.TBZP0100` 註記為已刪除（刪除日期＝當天、刪除人員＝操作者工號）。

完成後畫面重新查詢，已刪除的檔案不會再出現，訊息欄顯示「刪除成功...」。之後在原單據畫面上，這些附件也不會再顯示。

> ⚠️ 【刪除】**沒有確認視窗**，按下就執行。若沒有勾選任何一筆，訊息仍會顯示「刪除成功」，但實際上沒有刪除任何檔案。

## 四、【DR附件檔案】頁籤

### 步驟 1：查詢

1. **info like**：輸入文件資訊（info）的關鍵字（**必填**），系統會用「包含此字串」的方式查詢。常用關鍵字：

   | 關鍵字 | 附件來源 |
   |---|---|
   | `MP05yl-` | 物料驗收線上簽核、工程勞務驗收線上簽核 |
   | `MP03-` | 採購端電子審規 |
   | `MP04-` | 請購端電子審規 |
   | `MPL` | 物料信用狀申請作業 |

   也可以輸入完整的單號做精確查詢，例如某張驗收單號。
2. 按【**查詢**】。

- 只列出**未鎖定、未列管**（LOCK＝N、MANAGED＝N）的附件，依文件資訊、檔案代碼排序，**一次最多 1,000 筆**。
- 沒輸入關鍵字時，畫面會跳出提示，不會查詢。

### 步驟 2：確認清單內容

| 欄位 | 說明 |
|---|---|
| 核取方塊 | 勾選要刪除的檔案；表頭可全選。 |
| 檔案代碼 | 檔案唯一編號。 |
| 檔案名稱 | 原始檔名。 |
| 超連結 | 點回原始單據畫面（需先在【檔案連結】建立 DR 對照）。 |
| 文件資訊(info) | 例如 `MP05yl-驗收單號＋項次`（項次 0000 為基本資料）、`MP03-MP031410009-53396826`（作業-會辦單號-廠商編號）。 |
| 上傳人員／上傳時間 | 上傳者工號姓名與時間。 |

### 步驟 3：刪除

勾選後按【**刪除**】，系統會刪除伺服器上的實體檔案，完成後重新查詢。

> ⚠️ **注意（目前程式行為）**：DR 頁籤的刪除**只刪實體檔案，不會更新 `DB.TBDRDC3` 的狀態**（LOCK、MANAGED 仍是 N）。所以刪除後再查詢，**已刪除的檔案仍會出現在清單中**，但實際檔案已經不存在，點開會失敗。
>
> 操作時請自行記錄已刪除的範圍（例如關鍵字與單號區間），避免重複處理或誤以為刪除失敗。

## 五、【檔案連結】頁籤

這個頁籤維護「附件 ↔ 原始單據畫面」的對照表（`DB.TBEAFILEMG`），前兩個頁籤的【超連結】欄就是從這裡取得。**它只是對照資料，新增或刪除都不會動到附件檔案本身。**

### 查詢

1. **資料庫**：選擇 DR、EA 或 MP。
2. 按【**查詢**】，列出該系統最近建立的 **200 筆**對照（依建立時間新到舊）。

| 欄位 | 說明 |
|---|---|
| 檔案代碼 | DR 附件的檔案代碼；ZP 附件固定為 0。 |
| 附件代碼 | ZP 附件的附件代碼（agentNo）；DR 附件固定為 0。 |
| 系統 | MP 或 EA。 |
| 畫面名稱 | 原始單據的畫面，例如「請購單作業主檔」「失能傷害事故報告」。 |
| 連結路徑 | 點超連結時開啟的網址。 |
| 文件資訊(info) | DR 的 info，或 EA 的「文件編號-文件類型-報表代碼」。 |

### 新增（建立對照）

1. **資料庫**選擇要建立的來源。
2. 按【**新增**】。系統會找出「**還沒建立對照**」的附件，自動建立對照，完成後訊息顯示「新增 N 個檔案連結成功」。

| 資料庫 | 會建立對照的附件 | 畫面名稱 |
|---|---|---|
| MP | 請購單主檔、請購單項次的附件（ZP） | 請購單作業主檔、請購單作業項次 |
| DR | 物料驗收（基本資料、項次）、工程勞務驗收、採購端電子審規、請購端電子審規、物料信用狀申請的附件（DR） | 物料驗收線上簽核作業基本資料／項次資料、工程勞務驗收線上簽核作業、採購端電子審規、請購端電子審規、物料信用狀申請作業 |
| EA | 安環績效管理各類文件的附件（ZP） | 依文件類型，例如失能傷害事故報告、主管巡視、關鍵記錄暨巡檢項目查核 |

- 每一類**每次最多處理 1,000 筆**。附件數量多時，請**重複按【新增】，直到顯示「新增 0 個檔案連結成功」**為止。
- **DR 建立的對照，系統欄會記成 MP**。要查看 DR 建立的對照，資料庫請選 **MP**；選 DR 查詢會查不到資料。
- EA 文件類型中，若該類型沒有對應的開啟畫面（例如風險評估類文件），對照仍會建立，但點超連結會開不起來，屬正常現象，請改用「同附件代碼檔案」確認內容。

### 刪除（移除對照）

勾選要移除的對照，按【**刪除**】。只會刪除對照資料，**不會刪除附件檔案**。沒有勾選時會顯示「沒有勾選項目，不可以執行刪除...」。

## 六、建議作業流程

1. **先建立檔案連結**：在【檔案連結】頁籤，依序選 MP、DR、EA 按【新增】，每一種都按到「新增 0 個」為止。
   - 對照資料最後一次大量建立是 2014 年 11 月，之後上傳的附件都還沒有對照，不先建立的話【超連結】欄會是空白。
2. **查出要下線的附件**：
   - ZP 附件：在【ZP附件檔案】選系統別與年限後查詢。
   - DR 附件：在【DR附件檔案】輸入關鍵字查詢。
3. **確認內容**：抽查【超連結】或【同附件代碼檔案】，確認附件已超過保存年限，且原單據已結案、不再需要附件。
4. **勾選並刪除**：勾選確認過的檔案，按【刪除】。
5. **確認結果**：
   - ZP 附件：重新查詢，已刪除的不會再出現。
   - DR 附件：會繼續出現在清單中（見第四節注意事項），請以自己的紀錄為準。

## 七、訊息說明

| 訊息 | 意思 | 處理方式 |
|---|---|---|
| 歡迎使用上傳附件檔案批次維護作業 | 查詢條件沒選齊（ZP 的系統別、年限；檔案連結的資料庫）。 | 補選條件後再查詢。 |
| 查詢時 系統別要輸入才可以... | DR 頁籤沒輸入 info 關鍵字。 | 輸入關鍵字後再查詢。 |
| ->請輸入info like... | DR 頁籤沒輸入 info 關鍵字（伺服器端檢查）。 | 同上。 |
| 查詢成功...->無上傳檔案資料 | 條件下沒有符合的附件。 | 調整系統別、年限或關鍵字。 |
| ->沒輸入系統代碼，不能執行刪除功能。 | ZP 頁籤沒選系統別就按刪除。 | 先選系統別並查詢，再勾選刪除。 |
| 刪除成功... | 刪除已執行。 | ZP 頁籤沒勾選時也會出現這個訊息，請確認確實有勾選。 |
| 新增 N 個檔案連結成功 | 已建立 N 筆對照。 | N 不是 0 時，再按一次【新增】，直到 0 為止。 |
| 沒有勾選項目，不可以執行刪除... | 檔案連結頁籤沒勾選就按刪除。 | 勾選後再刪除。 |

## 八、常見問題

**Q1：刪除後可以救回來嗎？**
不行。系統會直接刪除伺服器上的實體檔案，只能請系統管理單位從備份還原。刪除前請務必確認。

**Q2：為什麼【超連結】是空白的？**
該附件還沒建立檔案連結對照。請到【檔案連結】頁籤選對應的資料庫，按【新增】建立後再查詢。

**Q3：為什麼查詢只出現 1,000 筆？**
每次查詢上限是 1,000 筆（檔案連結頁籤是 200 筆）。ZP 附件刪除一批後再查詢，就會帶出下一批。

**Q4：DR 附件刪除後為什麼還在清單裡？**
目前程式的 DR 刪除只刪實體檔案，沒有更新資料表狀態，所以清單仍會顯示。檔案其實已經刪除，請以自己的操作紀錄為準。

**Q5：年限「5 年前」是怎麼算的？**
以今天的日期往前推 5 年，上傳日期在那一天（含）以前的附件**全部**都會查出來。例如今天是 2026/11/10，會查出 2021/11/10（含）以前上傳的所有附件，包括 2015 年、2010 年的舊檔。所以選「1 年前」查到 2018 年的檔案是正常的。
