(EAJJRE00N) 風險評估 操作手冊

  • 系統：EA 安環績效管理系統
  • 依據：CVS 最新版程式
  • 編寫日期：2026/10/16

一、作業概要

風險評估以「部門」為單位建立，每次評估產生一個版次，依序完成下列作業：

順序 作業 簽核文件 說明
1 【風險評估】(EAJJRE00N，本作業) 風險評估 建立流程作業表、A 表、B 表，確認版次後送簽
2 【風險與機會評估】(EAJJRE10N) 風險與機會評估 風險評估簽核完成後，針對 B 表各項目評估機會（消除／取代）並送簽
3 【高風險改善追蹤】(EAJJRE20N) 每個高風險項目一份文件 風險等級 1、2 的項目，執行預估評估、完工、結果評估及簽核

【風險與機會評估】簽核完成，該版次才算完成，也才能作為下一版「新版複製」的來源。

1.1 整體流程

新增（或新版複製／複製）
  → 建立流程作業表 → 職務及作業清查表（A表） → 風險評估（B表）
  → 【確認】（產生版次）
  → 【送簽】 → 主管【核准】／【退回】
  → 風險評估簽核完成（新版複製的 HC 項目自動移轉高風險追蹤）
  → 【風險與機會評估】(EAJJRE10N) 送簽、簽核完成
  → 本版完成，部門才可新增下一版

四、操作步驟

4.1 新增風險評估

  1. 在查詢列輸入部門代號，按【查詢】。
  2. 選擇【評估原因】，輸入【部門】（可按放大鏡挑選）與【評估備註說明】。
  3. 按【新增】。成功後顯示「新增成功!共1筆」，版次、版次日期為空白。

版次管控

  • 系統參數 EA0013 REVerCtlDate（版次管控生效日）設定後，自生效日起，同部門前一版（最近建立的一版，年度 Y 與偶發 S 一起計算）必須【風險與機會評估】簽核完成，才可新增下一版。
  • 查詢時若前一版未完成，【新增】鈕旁會顯示紅字「(前一版尚未完成【風險與機會評估】簽核，暫不可新增)」，滑鼠移到紅字上可看到完整原因。
  • 按【新增】時若被擋，會跳出訊息，例如：
    • 「部門 M462 前一版風險評估(…)風險評估尚未簽核完成，需【風險與機會評估】簽核完成才可新增【風險評估】!」
    • 「…風險評估已簽核完成但尚未進入【風險與機會評估】…」
    • 「…【風險與機會評估】尚未簽核完成…」
  • 高風險追蹤文件的簽核不在管控範圍內。

4.2 新版複製（建議的改版方式）

適用：以部門最新完成版為基礎建立新版本。

  1. 先【新增】一筆空白的風險評估（版次空白）。
  2. 按【新版複製】（按鈕旁標示「(最新A、B表，含高風險、機會資料)」），確認提示後執行。
  3. 系統動作：
    • 來源：本部門【風險與機會評估】簽核完成的最新一版（年度 Y、偶發 S 一起比）。
    • 先刪除本版已輸入的流程作業表、A 表、B 表，再複製。
    • 流程作業表、A 表：原樣複製。
    • B 表：控制措施及風險值（工程控制、管理控制、個人防護具、暴露頻率、發生機率、嚴重度、風險等級）依下列原始依據取值，並記錄於每一列：
原始依據 條件 控制措施及風險值
RA－評估文號 一般項目 維持原風險評估內容
HR－高風險文號 風險等級 1、2，已完工評估且簽核完成 取改善後結果
HC－高風險文號 風險等級 1、2，尚未完工評估或未簽核完成 維持原內容；本版風險評估簽核完成時自動移轉（見 4.8）
RO－評估文號 風險等級 3 以上，具機會（消除／取代）改善 取機會評估內容
  1. 完成訊息範例：「新版複製完成!來源文號…；流程 16 筆、A表 12 筆、B表 1371 筆(RA …、RO …、HR …、HC …)」，並視情況附註：
    • 「HC n 筆將於本版風險評估核准後，自動移轉高風險追蹤並執行【預估評估】」
    • 「風險等級1、2但無高風險追蹤資料 n 筆，請於核准後至【高風險改善追蹤】自行預估評估」
  2. 複製後仍可自行修改各頁籤資料。
  3. 錯誤訊息：
    • 「已建立版次不可新版複製，複製會將原資料全部刪除!」→ 先【取消確認】。
    • 「非建立人不可新版複製!」
    • 「部門 xxx 查無【風險與機會評估】簽核完成之風險評估，無法新版複製!」→ 改用【複製】或手動建立。

4.3 複製（挑選版次）

  1. 先【新增】一筆空白的風險評估。
  2. 按【複製】，在彈出的清單中挑選來源版次（可換頁）。
  3. 系統先刪除本版的流程作業表、A 表、B 表，再從來源原樣複製；不含高風險追蹤及機會評估結果，也不記錄原始依據。
  4. 已確認（有版次）時不可複製：「已建立版次不可複製，複製會將原資料全部刪除!」

4.4 維護流程作業表、A 表、B 表

流程作業表

  • 第一層為「製程」，點【作業明細】進入第二層「作業」；代碼 2 碼、名稱、順序。
  • 【插入】可在序號中間插入；【回上層】回到製程層。
  • 每列的【刪除明細】可刪除該製程或作業底下的「作業明細」、「職務及作業清查表」、「風險評估」資料（兩次確認，刪除後無法復原）。

職務及作業清查表（A 表）

  • 依製程、作業輸入：狀態（正常／保養／異常處理）、性質（例行／非例行）、職務、作業環境、機械設備工具、物料化學品、危害特性、作業資格。
  • 【風險】可直接切到該作業的 B 表；【回流程作業表第一層】回到流程作業表。

風險評估（B 表）

  • 每列輸入作業流程、步驟、可能發生原因、後果影響、事故類型、暴露頻率、發生機率、嚴重度、工程控制、管理控制、個人防護具。
  • 風險等級由系統依暴露頻率、發生機率、嚴重度自動計算；點欄位標題按鈕可查看評分標準。
  • 風險等級 1、2 會出現【簽】（開啟高風險改善追蹤簽核畫面）及高風險追蹤圖示。
  • 同一製程＋作業的第一列以紅底顯示，其餘以藍綠底顯示。
  • 原始依據：新版複製產生的列，在作業流程名稱下方顯示藍字「原始依據：類型－文號」；HC 尚未移轉時加註紅字「（核准後移轉）」，已移轉時加註「（已移轉）」。
  • 資料超過 1000 筆時，請用製程＋作業查詢。

確認後（已有版次）流程作業表、A 表、B 表都不能異動，會顯示「已建立版本資料不可做任何資料異動!」；需修改請先【取消確認】。

4.5 確認（產生版次）

按【確認】時系統依序檢查，任一項不通過即列出所有問題，不產生版次：

  1. 至少有一筆製程資料（「查無任何製程資料，請填寫"流程作業表"摺頁」）。
  2. 每個製程底下至少有一筆作業。
  3. 每個作業至少有一筆職務及作業清查資料。
  4. 每筆清查資料的每個危害特性，在 B 表都有對應事故類型的風險評估。

通過後：版次＝同部門同評估原因前一版＋1（第一版為 01），版次日期＝今天，舊版改為非現行版，顯示「版本確認成功!最新版次:xx」。

注意

  • 送簽前必須先按【確認】，未確認直接送簽會顯示「->送簽失敗，請先執行【確認】產生版次」。
  • 已確認的版次不可刪除、複製、新版複製，也不可修改流程、A 表、B 表；需要時先【取消確認】。

4.6 送簽

  1. 至【簽核主管】頁籤設定各關簽核主管。
  2. 回【風險評估版次資料】，可在【加註意見】輸入說明。
  3. 按【送簽】，成功顯示「->已送簽成功,…」，文件進入簽核中。
  4. 部門對應關係未設定時會顯示「查無該部門(xxx)對應關係，請將問題反映給工安課。」，請洽工安課。

4.7 主管核准、退回、強制取回

  • 主管在待辦點入後，可輸入【加註意見】，按【核准】或【退回】。
  • 本單若有新版複製的 HC 項目，【核准】鈕旁會顯示紅字「(簽核完成後將自動移轉高風險追蹤 n 筆並執行【預估評估】)」，按【核准】時會再跳出確認視窗。
  • 發文者可在簽核中按【強制取回】收回文件；簽核完成的文件不能取回。

4.8 風險評估簽核完成：HC 項目自動移轉

最後一關核准、風險評估簽核完成時，系統在同一交易內對 B 表 HC 列逐筆處理：

  1. 重新讀取原高風險文號的最新狀態；下列情況跳過不移轉：本版已改成風險等級 3 以上、原高風險文號不存在、原文件最新改善版已完工評估且簽核完成、本版該項目已有高風險資料。
  2. 複製原高風險文件的異動歷程，改以核准日為版次日期，執行【預估評估】，產生新的高風險文號（發文者暫存，發文者為本版評估人）。
  3. 歷程備註記載「由高風險文號 ○○ 移轉」；預估完工日已過期時沿用原日期並註記逾期，請評估人到 EAJJRE20N 修改。
  4. 原高風險文號鎖定，在 EAJJRE20N 會提示「此高風險項目已於新版風險評估(○○)核准時移轉，請至新版處理，本項目不可再異動!」。
  5. 移轉成功時，系統發 DW 待辦訊息通知評估人（連結可開啟本單）；通知失敗不影響核准。
  6. 單筆移轉失敗只跳過並列入核准訊息，不會擋住核准。

評估人收到通知後，請至【高風險改善追蹤】(EAJJRE20N) 確認新文件內容並送簽。

4.9 風險與機會評估（EAJJRE10N）

風險評估簽核完成後，至【風險與機會評估】作業對 B 表各項目評估機會並送簽。

  • 原風險等級 1、2（高風險）的項目不可在風險與機會評估中輸入，勾選框停用並以紅字說明，須改至【高風險改善追蹤】處理。
  • 【風險與機會評估】簽核完成後，本版次完成。

五、匯入與匯出

表頭有資料（已新增）後才出現匯入、匯出功能。

5.1 匯出

選項 內容 可否再匯入
流程圖 每列一個製程：第 1 欄「製程代碼_名稱」，其後各欄「製程代碼-作業代碼_名稱」 可，用「流程圖」匯入
A表 本單職務及作業清查表 可
B表 本單風險評估 可
高風險 本單風險等級 1、2 項目 否
最新A表 本部門【風險與機會評估】簽核完成最新版的 A 表，格式同 A 表 可，用「A表」匯入
最新B表 同上最新版的 B 表，末欄「關聯文件編號」標示控制措施及風險值來源（RA／HR／HC／RO，定義同 4.2） 否（參考用）

按【匯出】後出現「下載連結」並自動開啟下載。匯出檔為 MS950（Big5）編碼的 CSV，內容含逗號、換行時會自動加雙引號，「銹」等擴充字會轉為標準字，Excel 可直接開啟。

5.2 匯入

  1. 按【選擇資料檔案】上傳 CSV。
  2. 選擇匯入類型（A表、B表、流程圖），按【匯入】。

規則：

  • 只接受 CSV 檔；可用 MS950（Big5）或 UTF-8（含 BOM）編碼。內容含逗號或換行時須以雙引號包覆，建議直接用 Excel 另存 CSV。
  • 檔案中的標點符號請用全形。
  • 匯入順序：流程圖 → A表 → B表。
  • 流程圖只能匯入尚無流程作業資料的表單；檢查格式、製程代碼一致、代碼不超過 3 碼、名稱不超過 50 個中文字、代碼不重複；順序依檔案先後編號。
  • A表、B表匯入時會檢查流程作業表，任一列的流程不存在就整批不匯入。
  • 編號的部門須與本單相同。
  • 任一列有錯，整批回復，不會只匯入一部分。

六、高風險未完成通知（排程）

系統排程定期寄送「高風險追蹤改善未完成案件清單」給相關部門的股長、課長、廠處長及工安負責人（附 CSV 檔），清單規則：

  • 每個部門只列最新一版風險評估的高風險項目，同一項目只列最新改善版。
  • 已完工評估且高風險文件簽核完成的項目不列入。
  • 狀態欄顯示：待預估評估、已預估評估待完工、完工延期中、已完工評估簽核中、退回待重新評估、風險評估核准後移轉、尚無資料等；並新增「高風險文號」欄。
