(EAJJRE10N) 風險與機會評估 操作手冊

  • 系統：EA 安環績效管理系統
  • 依據：CVS 最新版程式
  • 編寫日期：2026/10/16
  • 修訂日期：2026/10/21

一、作業概要

【風險評估】(EAJJRE00N) 簽核完成後，由評估人在本作業針對 B 表各項目評估是否有「機會」，也就是以消除或取代的方式進一步降低風險，並送主管簽核。本作業簽核完成，該版風險評估才算完成。

項目 說明
前提 該風險評估必須已簽核完成
操作人員 該風險評估的發文者（評估人）；其他人只能查詢
評估對象 B 表中風險等級 3 以上的項目；原風險等級 1、2（高風險）的項目改由【高風險改善追蹤】(EAJJRE20N) 處理
送簽條件 所有高風險項目都已在【高風險改善追蹤】完成預估評估
完成結果 簽核完成後，該版風險評估成為部門最新完成版，下一版才可新增，也才能作為【新版複製】的來源

1.1 整體流程

風險評估簽核完成
  → 【新增機會】或在【明細資料】頁籤直接【增修】
  → 逐項輸入改善方法、機會、改善後控制措施及風險值
  → 確認所有高風險項目都已完成預估評估（EAJJRE20N）
  → 【送簽】 → 主管【核准】／【退回】
  → 簽核完成，本版風險評估完成

3.1 基本資料頁籤

按鈕 何時出現 說明
新增機會 風險評估已簽核完成、尚未開始風險與機會評估；限發文者 開始風險與機會評估，並依 B 表建立機會評估明細
送簽 風險與機會評估為發文者暫存；限發文者 送出風險與機會評估簽核（見 5.4）

3.2 明細資料頁籤

按鈕 何時出現 說明
增修 風險評估已簽核完成，或風險與機會評估為發文者暫存；限發文者 儲存勾選列的機會評估內容（見 5.2）

四、明細資料畫面

每個 B 表項目佔三列：

列 內容 可否輸入
第 1 列 勾選框、作業流程名稱、步驟、可能發生原因、後果影響、事故類型 唯讀（勾選框除外）
第 2 列 序號、原始暴露頻率、發生機率、嚴重度、風險等級、工程控制、管理控制、個人防護具 唯讀
第 3 列 改善方法、機會、改善後暴露頻率、發生機率、嚴重度、風險等級、工程控制、管理控制、個人防護具 可輸入
欄位 說明
改善方法 下拉選單：消除、取代
機會 勾選表示本項目有機會改善
暴露頻率、發生機率、嚴重度 改善後的評分；點標題按鈕可查看評分標準
風險等級 由系統依改善後的暴露頻率、發生機率、嚴重度自動計算；三項有任一未填時為 0
工程控制、管理控制、個人防護具 改善後的控制措施
  • 同一製程＋作業的第一列以紅底顯示，其餘以藍綠底顯示。
  • 變更第 3 列任一欄位，系統會自動勾選該項目，按【增修】時一併儲存。
  • 原風險等級 1、2（高風險）的項目，勾選框停用，畫面上方以紅字提示「※原風險等級1、2(高風險)之項目，請至【高風險改善追蹤】輸入，本畫面不可勾選增修。」，滑鼠移到勾選框可看到說明。

五、操作步驟

5.1 開始風險與機會評估

  1. 在查詢列輸入風險評估文件編號，按【查詢】。
  2. 確認狀態為風險評估簽核完成。
  3. 按【新增機會】，系統依 B 表建立機會評估明細，文件狀態改為發文者暫存，顯示「新增成功」。

也可以直接到【明細資料】頁籤輸入後按【增修】，系統會自動開始風險與機會評估。

5.2 輸入機會評估（增修）

  1. 切到【明細資料】頁籤。
  2. 對有機會改善的項目，在第 3 列選擇改善方法（消除／取代）、勾選機會，輸入改善後的暴露頻率、發生機率、嚴重度及控制措施。
  3. 確認要儲存的項目已勾選（變更欄位時會自動勾選）。
  4. 按【增修】，成功顯示「增修成功!共 n 筆」。

錯誤訊息：

訊息 原因／處理
->沒有勾選要修改的項目,無法增修.. 請勾選要儲存的項目
->製程xx作業xx序號n為高風險(原等級1、2)，請至【高風險改善追蹤】輸入，不可於【風險與機會評估】輸入! 高風險項目請在 EAJJRE20N 處理
->此文件編號的風險評估資料還沒簽核完成,無法增修.. 請先完成風險評估簽核
->此文件編號的風險與機會評估資料已簽核完成,無法增修.. 已簽核完成，不可再修改
->文件狀態不是發文者暫存,無法增修.. 簽核中不可修改；需修改請先【強制取回】或請主管退回

5.3 確認高風險項目已完成預估評估

B 表中風險等級 1、2 的項目，必須都已在【高風險改善追蹤】(EAJJRE20N) 完成【預估評估】，才可送簽。

若有高風險項目尚未預估評估，【基本資料】按鈕旁會出現紅底大字「高風險無改善追蹤措施」，滑鼠移到紅字上可看到缺少的項目，例如：

作業10-01序號3
作業20-05序號12
高風險無改善追蹤措施!

請至 EAJJRE20N 逐項完成預估評估（可由風險評估 B 表的【簽】按鈕進入）。

5.4 送簽

  1. 至【簽核主管】頁籤設定簽核主管。
  2. 回【基本資料】頁籤，可在【加註意見】輸入說明。
  3. 按【送簽】，成功顯示「->已送簽成功,…」。
  4. 若仍有高風險項目未完成預估評估，送簽會被擋下，並列出缺少的項目。

5.5 主管核准、退回、強制取回

  • 簽核主管開啟文件後，可輸入【加註意見】，按【核准】或【退回】。
  • 退回後回到發文者暫存，發文者可修改後再送簽。
  • 發文者可在簽核中按【強制取回】收回文件。
  • 最後一關核准後簽核完成，本版風險評估完成。

六、匯入與匯出

6.1 匯出

在【基本資料】按【匯出】，訊息欄出現「產製完成!點我下載」，點連結下載 CSV。內容共 24 欄：

欄位群組 欄位
項目資料 項次、風險評估編號（部門-製程-作業-序號）、作業流程/名稱、狀態、步驟、可能發生原因、後果影響、事故類型
原始風險 工程控制、管理控制、個人防護具、暴露頻率、發生機率、嚴重度、風險等級
機會評估 改善方法、工程控制、管理控制、個人防護具、機會、暴露頻率、發生機率、嚴重度、風險等級

6.2 匯入

  1. 按【選擇資料檔案】上傳 CSV。
  2. 按【匯入】，成功顯示上傳筆數。

規則：

  • 只接受 CSV 檔，建議用匯出的檔案修改後匯入；檔案中的標點符號請用全形。內容含逗號或換行時須以雙引號包覆，建議直接用 Excel 另存 CSV。
  • 每列以「風險評估編號」（部門-製程-作業-序號）對應項目；部門須與本單相同。
  • 支援 24 欄（匯出格式）與 17 欄兩種格式；欄數不符會顯示「上傳檔案表單內容，第 n 欄的欄位數太少／太多」。
  • 匯入的改善後風險等級由系統計算；暴露頻率、發生機率、嚴重度有任一空白時為 0。
  • 機會欄填 V 表示有機會改善。
  • 原風險等級 1、2（高風險）的項目不可匯入機會資料：
    • 該列機會評估各欄（改善方法～嚴重度）全部空白時，系統略過該列，不匯入、不計入上傳筆數。
    • 該列有填任何機會評估欄位時，整批不匯入，並顯示「第 n 列有誤!…->製程xx作業xx序號n為高風險(原等級1、2)，請至【高風險改善追蹤】輸入，不可於【風險與機會評估】匯入機會資料!」；請清空該列機會評估欄位後重新匯入，高風險項目改至【高風險改善追蹤】(EAJJRE20N) 處理。
    • 原等級以系統中 B 表的風險等級為準，不是 CSV 中的「風險等級」欄。

七、機會評估結果的用途

改善方法為消除或取代的項目，在部門下一版風險評估執行【新版複製】、或匯出「最新B表」時，會以機會評估的控制措施及風險值取代原值，原始依據標示為「RO-風險評估文號」。

八、常見問題

問題 說明
看不到【新增機會】 風險評估尚未簽核完成、已開始風險與機會評估，或您不是發文者
高風險項目不能勾選 原等級 1、2 須在【高風險改善追蹤】(EAJJRE20N) 處理
匯入時出現「為高風險(原等級1、2)…不可於【風險與機會評估】匯入機會資料」 CSV 中高風險項目填了機會資料，請清空該列機會評估欄位後重新匯入（見 6.2）
出現「高風險無改善追蹤措施」 有高風險項目尚未預估評估，請至 EAJJRE20N 完成後再送簽
簽核中想修改 先【強制取回】，或請主管退回
簽核完成後還能修改嗎 不可以；請在部門下一版風險評估處理
部門無法新增下一版風險評估 本作業尚未簽核完成；完成後才可新增下一版
