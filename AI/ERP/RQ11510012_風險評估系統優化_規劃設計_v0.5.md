## 3. 各需求最終做法（as-built）

> 只記與 v0.4 不同或 v0.4 未定的部分；未提到的細節以 v0.4 第 3 節為準。

### 3.1 R1 版次管控（`eajcRE00CRN`）

- `checkVerCtl()`：系統日 ≥ EA0013 `REVerCtlDate` 時，新增前檢查**同部門前一版**（Y／S 一起，WorkDoc.timeStamp 最新者）必須為 `reportID='0002' AND docStatus='E'`；不檢查高風險簽核。
- 檢查邏輯抽成 `public static getVerCtlMsg(dsCom, compId, dept)`，後端新增與前端 AJAX（動作 `VC`，`doCheckVerCtl`，forward `zafjAJAX.jsp`）共用。
- 前端：`actionN()` 前先呼叫 `verCtlCK()`，被擋時跳 alert；查詢部門前一版未完成時，新增鈕旁顯示紅字（title 為完整原因）。

### 3.2 R2 畫面（`eajjRE00MainN.jsp`、`eajcRERpt`）

- 匯出下拉：`L=最新B表`（已上線）、**`M=最新A表`**（格式同 A 表，可直接匯入）。
- `LATEST_RA` 抽成共用 `getLatestRaSql()`，最新A表、最新B表、新版複製共用。
- 匯入下拉：**`F=流程圖`**；匯入說明列出順序（流程圖 → A 表 → B 表）與第 4 點「A、B 表匯入會檢查流程作業表」。
- 新增【新版複製】按鈕（動作 `CL`）；原【複製】保留（Q4）。

### 3.3 R3 新版複製（`eajcRE00CRN.doCopyLatest()`）

- `eajcRERpt`：最新B表 SQL 抽成 `getLatestBSql(forCopy)`，另有 `queryLatestBForCopy()`、`getLatestRaFormNo()`。
- RE03 逐列寫入，`refType`／`refDocNo` 依 RA／RO／HR／HC 記錄原始依據（對照表見 v0.4 3.3.2）；HC 列 `hcTransDate` 空白，等核准時移轉。
- 正式機唯讀驗證（10/15）：M462 1,371 筆全為 RA；MPW1 125 筆（HC 1、RA 124）。
- **B8**（`eajjRE03MainN.jsp`）：作業流程名稱下顯示「原始依據：refType-refDocNo」；HC 未移轉紅字「（核准後移轉）」，已移轉標「（已移轉）」。
- 原【複製】（`copyByFormNo()`）**不複製**三個新欄位（Q-B5）。

### 3.4 R4 高風險移轉（`eajcRE20CRN`、`eajcRE00CRN.agree()`）

- `estimate()`：`doEstimate()` 的寫入動作抽成 static 共用方法；不檢查操作者是否為建立人（由 `doEstimate()` 自己檢查）。
- `transferHC()`：第一階段核准成 `0001/E` 時，在 `agree()` 同一交易呼叫；掃 `refType='HC' AND hcTransDate=''`，**savepoint 逐筆**，有問題的列跳過並列入訊息，不擋核准；複製 RE043 時 versDate 改成核准日；memo 註記移轉來源與逾期。
- `getWorkDocNumber()` 取號修正：只取長度＝鍵＋3 碼的文號，不再吃掉錯誤（v0.4 3.4.6）。
- **B2 鎖定**：`isCanExecuteHrisk()` 以 `getTransferredFormNo()` 查舊文號是否已移轉，已移轉就鎖住。
- **B10**：`countPendingHC()` 計算本單未移轉 HC 筆數；核准鈕旁紅字提示，`actionA()` 跳確認視窗。
- **B7**：移轉成功 ≥1 筆時，以 `zpjcDwMsg.throwDwMsgUrl()` 發 DW 訊息給 `re00.createId`，附新高風險文號與連結 `/erp/ea/do?_pageId=eajjRE00N&_action=F&compId_qry=…&dept_qry=…&formNo_qry=…`（內容 ≤300 字）。

### 3.5 R5 機會評估不可輸入高風險

- `eajcRE13CRN.update()`：原等級 1、2 拋錯，提示改至【高風險改善追蹤】。
- `eajjRE13MainN.jsp`：該列勾選框停用＋紅字說明。
- **匯入補強**（`eajcRE10CRN` 1.22，`skipHighRisk()`）：以 RE03 的 rank 判斷原等級；該列機會欄位（17 欄格式 arr[8～15]、24 欄格式 arr[15～22]）有值就整批擋，全空就略過不計筆數。R5 前已填機會資料的舊單，重新匯入會被擋，要先清空。

### 3.6 RE03 加欄位（DDL 與 DAO）

- 正式機已加 `refType VARCHAR(2)`、`refDocNo VARCHAR(40)`、`hcTransDate VARCHAR(8)`（`NOT NULL WITH DEFAULT ''`）及索引 **`IXEARE03_REF (refDocNo, refType)`**（2026-10-27 查 `SYSCAT.COLUMNS`／`SYSCAT.INDEXES` 確認）。
- DDL 以資料庫異動申請表 ODT 申請（`20261015-ERP資料庫異動作業表格-修改表格TBEARE03.odt`），**不提交 CVS**。
- `eajcRE03.dao` 1.3、`eajcRE03VO` 1.5、`eajcRE03DAO` 1.12：daotool 重新產生並搬回手寫方法；**`update()`／`getUpdatePreSql()`／`prepareUpdate()` 的 SET 已拿掉新欄位**，畫面修改不會清掉追蹤資料（v0.4 3.6.2）。
