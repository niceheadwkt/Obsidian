  在 Ava GPT 平台架構中，「底層推論模型 (Models)」 與 「專家角色 (Experts)」/「知識庫 (Datasets)」 屬於不同層級的物件：

  • 底層推論模型 (LLM)：採用 數值整數 ID（如 1、12、75），用於多模態視覺辨識 API (uploadFilesLlmApi) 的 model_list_id。
  • 專家角色 (Experts)：採用 UUID 格式的識別碼（即程式碼中的 EXPERT_ID），用於純文字知識庫問答 API (/ava/chat/rag/query)。
  • 知識庫 (Datasets)：同樣採用 UUID 格式 作為 datasets_id。
